# \[FPGA\] 조합·순차논리와 Verilog 주요 문법

<a id="notion-3fa1d46c18fc806c97d7c5a036c66a4e"></a>

## 비교기 Comparator

두 입력값의 크기나 같은지를 비교하는 조합논리회로이다.

```verilog
assign eq = (a == b);
assign gt = (a > b);
assign lt = (a < b);
```

- `eq` : 같은지
- `gt` : a가 큰지
- `lt` : a가 작은지

<a id="notion-3fa1d46c18fc80cda68fe01f8206c31a"></a>

## ROM

주소 `addr`를 입력하면 해당 주소에 저장된 데이터를 출력하는 메모리이다.

```verilog
always @(*) begin
  case (addr)
    4'h0: dataout = 8'h23;
    4'h1: dataout = 8'hf3;
    4'h2: dataout = 8'ha7;
    default: dataout = 8'hxx;
  endcase
end
```

예:

```text
addr = 4'h2
→ dataout = 8'ha7
```

<a id="notion-3fa1d46c18fc803aa325d2e75a1121b7"></a>

## Latch 방지

조합논리 `always`에서는 **모든 조건에서 출력값이 결정되어야 한다.**

잘못된 예:

```verilog
always @(*) begin
  if (sel)
    out = a;
end
```

`sel = 0`일 때 `out` 값이 지정되지 않아 이전 값을 유지해야 하므로 Latch가 추론될 수 있다.

수정:

```verilog
always @(*) begin
  if (sel)
    out = a;
  else
    out = b;
end
```

또는 처음에 기본값을 지정한다.

```verilog
always @(*) begin
  out = b;

  if (sel)
    out = a;
end
```

## 순차논리회로

순차논리회로는 **현재 입력뿐 아니라 이전 상태를 저장하여 사용하는 회로**이다.

대표적으로:

- Flip-Flop
- Register
- Counter
- FSM

등이 있다.

주로 Clock의 Edge에서 값이 변경된다.

```verilog
always @(posedge clk) begin
  q <= d;
end
```

---

<a id="notion-3fa1d46c18fc8003bc92deac4d0f1b04"></a>

## D Flip-Flop

Clock의 Rising Edge에서 입력 `d`를 저장한다.

```verilog
always @(posedge clk) begin
  q <= d;
end
```

```text
posedge clk 발생
→ d 값을 저장
→ q로 출력
```

<a id="notion-3fa1d46c18fc801ab10df16882be376c"></a>

### 비동기 Reset DFF

Reset 신호가 들어오면 Clock을 기다리지 않고 즉시 초기화한다.

```verilog
always @(posedge clk or negedge reset_n) begin
  if (!reset_n)
    q <= 1'b0;
  else
    q <= d;
end
```

- `posedge clk` : Clock 상승 Edge
- `negedge reset_n` : Reset 하강 Edge
- `reset_n = 0` : 즉시 Reset

---

<a id="notion-3fa1d46c18fc80d9b3b0da8fa98a4799"></a>

## 4-bit DFF

1bit DFF 여러 개를 묶어 여러 bit를 한 번에 저장할 수 있다.

```verilog
reg [3:0] q;

always @(posedge clk or negedge reset_n) begin
  if (!reset_n)
    q <= 4'b0000;
  else
    q <= d;
end
```

실제로는 4개의 bit를 저장하므로 여러 Flip-Flop이 사용된다.

## 조합논리와 순차논리의 기술 방법

| 구분 | 조합논리 | 조합논리 | 순차논리 |
| --- | --- | --- | --- |
| 작성 | `assign` | `always` | `always` |
| 출력 | `wire` | `reg` | `reg` |
| Sensitivity | 없음 | `@(*)` | Clock/Reset 등의 Edge |
| 할당 | `=` | `=` | `<=` |
| 종류 | Continuous | Blocking | Non-blocking |

예:

```verilog
// 조합논리
assign y = a & b;
```

```verilog
// 조합논리
always @(*) begin
  y = a & b;
end
```

```verilog
// 순차논리
always @(posedge clk) begin
  q <= d;
end
```

<a id="notion-3fa1d46c18fc805f992cdcd3e72cf0c5"></a>

## Flip-Flop 작성 시 Non-blocking 사용

순차논리에서는 일반적으로 `<=`를 사용한다.

```verilog
always @(posedge clk) begin
  q1 <= d;
  q2 <= q1;
end
```

Clock Edge를 기준으로 각 Flip-Flop이 이전 값을 이용해 갱신되는 하드웨어 동작을 표현하기 적합하다.

```text
조합논리 → =
순차논리 → <=
```

<a id="notion-3fa1d46c18fc809b922bc7ea7c43f871"></a>

## 출력 신호는 한 블록에서만 할당

하나의 신호를 여러 `always` 블록에서 동시에 출력하지 않도록 한다.

잘못된 예:

```verilog
always @(posedge clk)
  q <= a;

always @(posedge clk)
  q <= b;
```

`q`를 어떤 회로가 구동해야 하는지 충돌하게 된다.

따라서 **하나의 출력 신호는 하나의 블록에서 담당**하도록 작성한다.

## 이벤트 기호 `@`

특정 신호가 변하는 시점을 감지한다.

```verilog
always @(a or b)
```

`a` 또는 `b`가 변경되면 블록을 다시 평가한다.

```verilog
always @(*)
```

블록에서 읽는 신호들을 자동으로 Sensitivity List에 포함한다.

순차회로에서는 Edge를 지정할 수 있다.

```verilog
@(posedge clk)
@(negedge reset_n)
```

# \[FPGA\] Button Debounce와 Single Pulse

<a id="notion-3fa1d46c18fc80799b33f72d106fd4ad"></a>

## Button Bounce

기계식 버튼을 누르거나 뗄 때 접점이 한 번에 안정되지 않고 짧은 시간 동안 `0 ↔ 1`이 여러 번 반복되는 현상을 **Bounce(바운스)** 또는 \*\*Chatter(채터)\*\*라고 한다.

```text
정상 신호
0 ──────── 1 ────────

실제 버튼 신호
0 ──── 1010111 ──────
       ↑ Bounce
```

버튼을 한 번 눌렀는데 여러 번 누른 것으로 인식될 수 있다.

---

<a id="notion-3fa1d46c18fc80ffbe97fff47bb53b1f"></a>

## Debounce

**Debounce**는 버튼 입력이 일정 시간 동안 변하지 않을 때만 안정된 값으로 인정하여 Bounce를 제거하는 방법이다.

보통 약 **10ms 정도 입력이 유지되면 안정된 값**으로 판단한다.

```text
0 → 1 변화
   ↓
약 10ms 동안 1 유지
   ↓
안정된 1로 판단
```

`1 → 0`도 같은 방식으로 처리한다.

---

<a id="notion-3fa1d46c18fc806b8cc0ea314e568599"></a>

## FPGA에서의 Button Debounce

FPGA에서는 버튼의 불안정한 입력을 Debounce한 뒤 **한 번의 버튼 입력에 대해 하나의 Pulse**를 만들 수 있다.

```text
Push Button
    ↓
  DFF_1 → Q1
    ↓
  DFF_2 → Q2
    ↓
Single Pulse
```

DFF 두 개의 출력 시점 차이를 이용해 버튼이 눌린 순간을 검출한다.

```verilog
pulse = Q1 & ~Q2;
```

- `Q1` : 현재 입력에 가까운 값
- `Q2` : 한 Clock 이전 값
- `Q1 & ~Q2` : `0 → 1`로 변한 순간 검출

---

<a id="notion-3fa1d46c18fc800d8bc4fc962ad38e31"></a>

## 100MHz Clock과 Debounce 시간

Basys3의 기본 Clock이 `100MHz`라면:

```text
1 Clock = 10ns
```

약 `80Hz`의 느린 신호를 만들려면:

```text
100,000,000 / 80
= 1,250,000 Clock
```

따라서:

```text
10ns × 1,250,000
= 12.5ms
```

즉 **100MHz Clock을 1,250,000번 세면 약 12.5ms**가 된다.

50% Duty의 Clock이라면 반 주기는:

```text
1,250,000 / 2
= 625,000 Clock
```

625,000 Clock마다 신호를 반전하면 된다.

---

<a id="notion-3fa1d46c18fc80e89e96d64a2902e09a"></a>

## 핵심

```text
Button
  ↓
Bounce 발생
  ↓
Debounce
  ↓
안정된 버튼 신호
  ↓
DFF를 이용한 Edge 검출
  ↓
Single Pulse
```

- **Bounce** : 버튼 접점 때문에 `0/1`이 여러 번 흔들리는 현상
- **Debounce** : 일정 시간 유지된 값만 정상 입력으로 판단
- **DFF** : 현재 값과 이전 값을 저장
- **Single Pulse** : 버튼 한 번에 한 번만 발생하는 신호
- **Clock Divider** : 100MHz Clock을 느리게 만들어 Debounce 시간을 확보

# \[FPGA\] Button Debounce와 LED Toggle

<a id="notion-3fa1d46c18fc8000a590c0e6b432ec7f"></a>

## 전체 동작

기계식 버튼은 한 번 눌러도 접점 때문에 짧은 시간 동안 `0 ↔ 1`이 여러 번 반복되는 **Bounce**가 발생할 수 있다.

따라서 FPGA에서는 버튼 입력을 그대로 사용하지 않고:

```text
Button
  ↓
Debounce
  ↓
Single Pulse
  ↓
LED Toggle
```

순서로 처리한다.

버튼을 한 번 누를 때마다 최종적으로 LED 상태가 한 번씩 바뀐다.

```text
버튼 1회 → LED ON
버튼 1회 → LED OFF
버튼 1회 → LED ON
...
```

---

<a id="notion-3fa1d46c18fc80d79fa7d3751b8e49ef"></a>

## 전체 모듈 구조

```text
top_btn_debounce
│
├─ button_debounce
│   ├─ clock_80hz
│   ├─ d_ff ①
│   └─ d_ff ②
│
└─ led_toggle
```

각 기능을 별도 Module로 분리하고 Top Module에서 연결한다.

---

<a id="notion-3fa1d46c18fc80b2a621de637c13be95"></a>

## Clock Divider

Basys3의 `100MHz` Clock은 주기가 `10ns`이다.

Debounce용으로 약 `80Hz`의 느린 Clock을 만든다.

```text
100MHz / 80Hz = 1,250,000

1주기 = 12.5ms
반주기 = 6.25ms

625,000 Clock마다 출력 반전
→ 약 80Hz
```

<a id="notion-3fa1d46c18fc806bb14df61bc7725f6c"></a>

### `clock_80hz.v`

```verilog
`timescale 1ns / 1ps

module clock_80hz (
    input  wire clk,
    input  wire reset,
    output reg  clk_80hz
);

  reg [19:0] count;

  always @(posedge clk or posedge reset) begin
    if (reset) begin
      count    <= 20'd0;
      clk_80hz <= 1'b0;
    end
    else if (count == 20'd624999) begin
      count    <= 20'd0;
      clk_80hz <= ~clk_80hz;
    end
    else begin
      count <= count + 1'b1;
    end
  end

endmodule
```

## D Flip-Flop

Clock의 Rising Edge마다 입력 `d`를 저장하여 `q`로 출력한다.

```text
posedge clk
→ q에 d 저장
```

<a id="notion-3fa1d46c18fc80c190bbd1147d146214"></a>

### `d_ff.v`

```verilog
`timescale 1ns / 1ps

module d_ff (
    input  wire clk,
    input  wire reset,
    input  wire d,
    output reg  q
);

  always @(posedge clk or posedge reset) begin
    if (reset)
      q <= 1'b0;
    else
      q <= d;
  end

endmodule
```

순차논리이므로 Non-blocking 할당인 `<=`를 사용한다.

<a id="notion-3fa1d46c18fc801cbaa3deb6180b930c"></a>

## Button Debounce / Single Pulse

느린 80Hz Clock으로 버튼 값을 DFF 2개에 순서대로 저장한다.

```text
button → DFF1 → q1 → DFF2 → q2
```

`q1`과 한 Clock 늦은 `q2`를 비교하여 버튼의 `0 → 1` 변화 순간만 검출한다.

```verilog
assign clean_btn = q1 & ~q2;
```

따라서 버튼을 계속 누르고 있어도 `clean_btn`은 한 번만 HIGH가 된다.

<a id="notion-3fa1d46c18fc800493aade03a20d9186"></a>

### `button_debounce.v`

```verilog
`timescale 1ns / 1ps

module button_debounce (
    input  wire clk,
    input  wire reset,
    input  wire btn_c,
    output wire clean_btn
);

  wire clk_80hz;
  wire q1;
  wire q2;

  clock_80hz u_clock_80hz (
      .clk     (clk),
      .reset   (reset),
      .clk_80hz(clk_80hz)
  );

  d_ff u_d_ff_0 (
      .clk  (clk_80hz),
      .reset(reset),
      .d    (btn_c),
      .q    (q1)
  );

  d_ff u_d_ff_1 (
      .clk  (clk_80hz),
      .reset(reset),
      .d    (q1),
      .q    (q2)
  );

  assign clean_btn = q1 & ~q2;

endmodule
```

## LED Toggle

Debounce된 버튼 신호의 Rising Edge가 발생할 때마다 LED 상태를 반전한다.

```text
현재 LED = 0
→ 버튼 입력
→ LED = 1

현재 LED = 1
→ 버튼 입력
→ LED = 0
```

<a id="notion-3fa1d46c18fc80a58930c485cc7f188f"></a>

### `led_toggle.v`

```verilog
`timescale 1ns / 1ps

module led_toggle (
    input  wire clean_btn,
    input  wire reset,
    output reg  led
);

  always @(posedge clean_btn or posedge reset) begin
    if (reset)
      led <= 1'b0;
    else
      led <= ~led;
  end

endmodule
```

`always @(clean_btn)`로 작성하면 상승과 하강 변화에 모두 반응하므로 LED가 한 Pulse에 두 번 반전될 수 있다.

따라서 버튼을 누른 순간만 사용하려면:

```verilog
always @(posedge clean_btn ...)
```

처럼 Rising Edge를 사용한다.

## 코드 구조에서 확인한 부분

<a id="notion-3fa1d46c18fc80a98387d7b021d9be0b"></a>

### 네이밍

파일명과 Module명을 같은 이름으로 맞추는 것이 관리하기 편하다.

```text
clock_80hz.v       → clock_80hz
d_ff.v             → d_ff
button_debounce.v  → button_debounce
led_toggle.v       → led_toggle
top_btn_debounce.v → top_btn_debounce
```

Module Instance는 `u_`를 붙여 구분한다.

```verilog
u_clock_80hz
u_d_ff_0
u_d_ff_1
u_button_debounce
u_led_toggle
```

<a id="notion-3fa1d46c18fc8010adf5ed5298beb622"></a>

### 불필요한 신호 제거

기존처럼:

```verilog
wire q2_bar;

assign q2_bar = ~q2;
assign clean_btn = q1 & q2_bar;
```

로 나눌 필요 없이:

```verilog
assign clean_btn = q1 & ~q2;
```

로 바로 표현할 수 있다.

---

<a id="notion-3fa1d46c18fc8081a34af15463bccfcb"></a>

### 출력 신호 연결 주의

Module 출력이:

```verilog
output wire clean_btn;
```

이면 실제로도 반드시 해당 신호에 대입해야 한다.

```verilog
assign clean_btn = q1 & ~q2;
```

다른 이름인 `w_clean_btn` 등에 잘못 대입하면 실제 `clean_btn` 출력이 연결되지 않는다.

## 최종 흐름

```text
100MHz Clock
     ↓
Clock Divider
     ↓
80Hz Clock
     ↓
Button
     ↓
DFF1
     ↓
DFF2
     ↓
q1 & ~q2
     ↓
Single Pulse
     ↓
LED Toggle
     ↓
버튼을 누를 때마다 LED ON/OFF
```

핵심은 **버튼의 불안정한 입력을 처리한 뒤 한 번의 Pulse로 만들고, 그 Pulse를 이용해 LED 상태를 한 번씩 변경하는 것**이다.
