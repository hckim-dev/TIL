**\[복습\]**

**1\. 비트 제어 핵심 공식 (Bit Masking)**<br>특정 위치(n번)의 비트를 켜고 끄는 실무 표준 패턴입니다.

<br>• <strong>비트 끄기 (Reset):</strong> **`c &= ~(1 << n)`**<br>    ◦ `1 << 31`로 31번 비트만 1로 만든 뒤, `~`로 뒤집어 **31번만 0이고 나머지는 1인 마스크**를 만듭니다. 이를 `&` 연산하여 31번 비트만 핀포인트로 꺼버립니다.

<br>• <strong>비트 켜기 (Set):</strong> **`c |= (1 << n)`**<br>    ◦ `1 << 31`로 31번 비트만 1인 마스크를 만든 뒤, `|` 연산하여 다른 비트는 보존하고 **31번 비트만 강제로 1**로 켭니다.

**<br>2\. 이진수 출력 함수 원리 요약**

```c
void print_binary(int num)
{
    // 7번(왼쪽)부터 0번(오른쪽) 비트까지 거꾸로 순회
    for (int i = 7; i >= 0; i--)
    {
        // [원리] i칸 밀어서(>> i) 맨 끝자리 비트만 필터링(& 1)
        int bit = (num >> i) & 1;
        printf("%d", bit);

        // 가독성: 4비트마다 공백 출력 (단, 맨 마지막 0번에서는 제외)
        if (i % 4 == 0 && i != 0)
        {
            printf(" ");
        }
    }
    printf("\n");
}
```

### 1\. strcpy (문자열 복사)

- **명칭:** String Copy (문자열 복사)
- **기능:** 오른쪽에 있는 문자열을 왼쪽에 있는 배열 공간에 그대로 복사해 넣습니다.
- **사용법:** `strcpy(대상_배열, 원본_문자열);`
- **특징 및 주의점:** \* C언어에서는 `배열1 = 배열2;` 같은 방식으로 문자열을 한 번에 대입할 수 없기 때문에 이 함수를 필수적으로 사용합니다.

  - 복사할 원본 문자열의 맨 끝에 있는 널 문자('\\0')까지 같이 복사해 줍니다.
  - **보안 취약점:** 복사될 대상 배열의 크기가 원본 문자열보다 작으면 메모리가 넘치는 '버퍼 오버플로우' 에러가 발생할 수 있습니다. (실무에서는 더 안전한 `strncpy`나 `strcpy_s`를 권장합니다.)

<a id="notion-3731d46c18fc80f29d0deedb8fa5cecd"></a>

### 2\. gets (문자열 입력)

- **명칭:** Get String (문자열 입력받기)
- **기능:** 키보드로 문자열을 입력받아 배열에 저장합니다.
- **사용법:** `gets(배열_이름);`
- **특징 및 주의점:**

  - `scanf("%s")`와 달리, **띄어쓰기(스페이스바)를 포함한 한 줄 전체를 통째로 입력**받을 수 있다는 큰 장점이 있습니다. 사용자가 엔터(Enter)를 누를 때까지 모두 읽어 들입니다.
  - **치명적인 단점:** 입력받을 배열의 크기를 지정하지 않고 무조건 담으려고 하기 때문에, 배열 크기보다 긴 문자열을 입력하면 프로그램이 터져버립니다.
  - 이 위험성 때문에 최신 C언어 표준에서는 `gets` 함수 사용을 아예 금지(Deprecated)하고 있으며, 대안으로 크기를 지정할 수 있는 `fgets`를 사용합니다.

<a id="notion-3731d46c18fc80f29fcafb571beb69ec"></a>

### 3\. puts (문자열 출력)

- **명칭:** Put String (문자열 출력하기)
- **기능:** 화면(콘솔)에 문자열을 출력합니다.
- **사용법:** `puts(배열_이름_또는_문자열);`
- **특징 및 주의점:**

  - `printf("%s\n", 문자열);`과 완벽히 같은 동작을 합니다.
  - **핵심 강점:** 문장을 출력한 뒤 **자동으로 줄바꿈('\\n')을 해줍니다.** 따라서 `\n`을 일일이 적지 않아도 되므로 문자열만 단순 출력할 때 코드가 아주 깔끔해집니다.
  - 다만 `printf`처럼 `%d`나 `%x` 같은 서식 지정자를 사용해서 변수 값을 섞어서 출력하는 기능은 불가능하고, 오직 순수한 문자열만 찍을 수 있습니다.

<a id="notion-3731d46c18fc8030915ae50f5e50eb09"></a>

### 📋 한 줄 요약 가이드

- <strong>`strcpy`</strong>: 문자열을 변수에 대입(복사)할 때 쓴다. (배열 크기 주의\!)
- <strong>`gets`</strong>: 띄어쓰기 포함해서 키보드로 한 줄 입력받을 때 쓴다. (위험해서 요즘은 `fgets` 권장)
- <strong>`puts`</strong>: 화면에 문자열을 찍고 자동으로 줄 바꿈까지 하고 싶을 때 쓴다.

**\[포인터\]**

<a id="notion-3731d46c18fc804fb1d6c4c8e574fa76"></a>

### 1\. 포인터의 본질 (개념 정의)

- **일반 변수:** 숫자(`10`)나 문자(`'A'`) 같은 **실제 데이터**를 저장하는 그릇입니다.
- **포인터 변수:** 다른 변수가 메모리 상에서 몇 번지에 살고 있는지, 그 **주소값**을 저장하는 전용 그릇입니다.

<a id="notion-3731d46c18fc8036adb6d463436bae54"></a>

### 2\. 포인터를 왜 사용할까? (가장 큰 이유)

- **메모리 직접 참조 (Access):** C언어에서 서로 다른 함수(예: `main` 함수와 내가 만든 사용자 정의 함수)는 자기 방에 있는 지역 변수를 서로 들여다볼 수 없습니다.<br>하지만 원본 변수의 주소(포인터)를 넘겨주면, 호출된 함수에서 외부 함수에 있는 변수 값을 직접 읽거나 수정(Access)할 수 있게 됩니다. 이를 통해 메모리를 낭비하지 않고 효율적으로 데이터를 제어할 수 있습니다.

<a id="notion-3731d46c18fc8040864be1c364028cbc"></a>

### 3\. 포인터 선언 및 주소 저장 방법

포인터를 선언할 때는 가리키고자 하는 원본 변수의 데이터 타입 뒤에 별표(`*`)를 붙입니다. 변수 이름은 포인터임을 알아보기 쉽게 맨 앞에 소문자 `p`를 붙이는 카멜 케이스 규칙을 주로 씁니다.

```c
int age = 20;     // 일반 변수 선언
int* pAge;        // int형 주소를 담을 포인터 변수 pAge 선언

pAge = &age;      // 주소 연산자(&)를 사용해 age의 메모리 주소를 포인터에 저장
```

<a id="notion-3731d46c18fc80979b55fce9d710b030"></a>

### 4\. 포인터 핵심 연산자 기호 2가지

포인터를 지배하는 기호는 딱 두 가지입니다. 돋보기(`&`)와 화살표(`*`)로 기억하시면 쉽습니다.

- **`&`** <strong>(주소 연산자): "너 어디 사니?"</strong>

  - 변수 앞에 붙이면 그 변수의 메모리 주소값을 알아냅니다.
- **`*`** <strong>(역참조 연산자 / 간접 참조 연산자): "그 주소로 가라\!"</strong>

  - 포인터 변수 앞에 붙이면, 포인터가 가리키고 있는 주소지로 직접 찾아가서 그곳에 있는 실제 데이터를 끄집어내거나 바꿉니다.

```c
printf("%p\n", pAge);  // age의 주소값이 출력됨 (예: 00xHEX...)
printf("%d\n", *pAge); // pAge가 가리키는 주소로 찾아가서 실제 값인 20을 출력함
```

<a id="notion-3731d46c18fc80e9a3f1d9a6a82f438c"></a>

### 💡 한 줄 요약

> **변수**는 데이터를 담고, **포인터**는 그 데이터가 있는 주소를 담는다\! 함수 간에 주소(`&`)를 주고받음으로써 다른 함수에 있는 원본 변수를 자유롭게 읽고 쓸(`*`) 수 있게 된다.

```c
/**
 * [개념 정리]
 * 1. 변수(Variable): 데이터를 담는 메모리 공간(그릇)
 * 2. 포인터(Pointer): 다른 메모리 공간의 '주소'를 담는 전용 공간
 * 3. 포인터 사용의 본질:
 * 호출된 함수에서 외부 함수(예: main)의 지역 변수에 직접 접근(Read/Write)하여
 * 메모리를 효율적으로 공유하고 원본 데이터를 제어하기 위함이다.
 */

#define ALPHABET_COUNT (26)

void shift_alpha(char* pAlpha);
void pointer_shift(char* pAlphaArray);

int main(void)
{
	// 뒤에 자동으로 \0이 붙으므로 총 27칸짜리 배열이 됩니다.
	char alpha[] = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";

	printf("원본 문자열 ==> %s\n\n", alpha);

	// 배열의 이름은 첫 번째 방의 시작 주소(alpha[0])를 의미합니다.
	//shift_alpha(alpha);
	pointer_shift(alpha);

	printf("\n");
	printf("alpha[0]의 주소: %p\n", (void*)alpha);
	printf("alpha[1]의 주소: %p\n", (void*)&alpha[1]);

	return 0;
}

/**
 * @brief 알파벳 배열을 한 칸씩 밀어가며 회전판 형태로 출력하는 함수
 * @param pAlpha 알파벳 문자열 배열의 시작 주소
 */
void shift_alpha(char* pAlpha)
{
	for (int i = 0; i < ALPHABET_COUNT; i++)
	{
		for (int j = 0; j < ALPHABET_COUNT; j++)
		{
			printf("%c", pAlpha[(i + j) % ALPHABET_COUNT]);
		}
		printf("\n");
	}
}

/**
 * @brief 포인터 이동 연산만을 사용하여 문자열 자체를 1칸씩 왼쪽으로 회전시키는 함수
 * @param pAlphaArray 알파벳 문자열 배열의 시작 주소
 */
void pointer_shift(char* pAlphaArray)
{
	char temp_char;
	char* pCurrent;

	for (int i = 0; i < ALPHABET_COUNT; i++)
	{
		// 1. 매 회전마다 포인터 위치를 배열의 시작점(0번 방)으로 초기화
		pCurrent = pAlphaArray;

		// 2. 현재 상태의 문자열 출력 (널 문자가 안전하게 보존되어 있으므로 %s 가능)
		printf("%s\n", pCurrent);

		// 3. 맨 앞 글자(0번 방)를 변수에 임시 대피
		temp_char = *pCurrent;

		// 4. 포인터 연산으로 뒤의 글자를 앞방으로 한 칸씩 당기기
		for (int j = 0; j < ALPHABET_COUNT - 1; j++)
		{
			*pCurrent = *(pCurrent + 1); // 다음 방의 값을 현재 방에 대입
			pCurrent++;                  // 다음 주소로 포인터 이동
		}

		// 5. 당기기가 끝나면 pCurrent는 마지막 방(25번 인덱스)에 도착해 있습니다.
		// 대피시켜 두었던 첫 글자를 이 마지막 방에 골인시킵니다.
		*pCurrent = temp_char;
	}
}
```

```c
// 실제 임베디드 개발 예시
#define LED_CONTROL_ADDR (0x3F0040) // 하드웨어 장치 주소
int* pLed = (int*)LED_CONTROL_ADDR;

*pLed = 1; // 1을 넣으면 하드웨어 LED 전등이 물리적으로 켜짐!
```

### 🔄 주소 연산자(&amp;)와 역참조 연산자(\*)의 역함수(상쇄) 관계

수학에서 더하기와 빼기, 곱하기와 나누기가 서로를 상쇄시켜 원래 숫자로 되돌리는 것처럼, C언어의 `&` (주소 구하기)와 \*\*`*` (주소로 찾아가기)도 완벽한 **역함수 관계**입니다.

따라서 두 기호가 연속으로 붙으면 서로의 효과를 완전히 없애버리고 **원본 변수 자기 자신**으로 돌아옵니다.

<a id="notion-3731d46c18fc8038a93bffb506014bb8"></a>

### 💻 코드로 보는 상쇄 현상

```c
int a = 10;
```

- <strong>`&a`</strong>: 변수 `a`의 **주소값**을 구합니다. (예: 100번지)
- <strong>`&a`</strong>: `&a`로 구한 주소(100번지)로 **다시 찾아갑니다.**

결국 "a의 주소를 구한 뒤, 다시 그 주소로 가라"가 되기 때문에, `*`와 `&`가 짝을 이뤄 펑 사라지고 그냥 `a`와 완벽히 똑같은 상태가 됩니다.

```c
printf("%d\n", *&a); // 'a'를 그냥 찍은 것과 똑같이 10이 출력됨
*&a = 30;            // 'a = 30;' 규칙과 완벽히 동일하게 변수 값이 바뀜
```

<a id="notion-3731d46c18fc80358715fe1747034ffe"></a>

### 📋 한 줄 요약

> `*`와 `&`는 서로 반대로 작동하는 **역함수 관계**이기 때문에, 변수 앞에 두 기호가 동시에 붙은 <strong>`*&변수`</strong><strong>는 기호가 전부 상쇄되어 그냥</strong> **`변수`** <strong>원본 자체</strong>가 된다\!

### 1\. L-value(좌변)와 R-value(우변)의 진짜 의미

많은 입문자가 단순히 대입 연산자(`=`)의 왼쪽/오른쪽 위치로만 기억하지만, 컴파일러 기준의 진짜 의미는 다음과 같습니다.

- **`L-value`** <strong>(Left-value / 좌변)</strong>

  - 실제 메모리 공간(위치)이 있는 녀석입니다. 값을 지속적으로 저장할 수 있는 고유한 주소를 가졌기 때문에 대입 연산자의 **왼쪽**에 올 수 있습니다. 물론 오른쪽에 와서 값을 채워주는 역할도 가능합니다.
- **`R-value`** <strong>(Right-value / 우변)</strong>

  - 한 번 쓰고 사라지는 임시 데이터(값 그 자체)입니다. 실제 지속 가능한 메모리 공간이 없기 때문에 오직 대입 연산자의 **오른쪽**에만 올 수 있고, 절대 왼쪽(L-value 자리)에 올 수 없습니다.

<a id="notion-3731d46c18fc805d99cfc77b8dd18328"></a>

### 2\. `*`와 `&` 연산자의 L-value / R-value 규칙

<a id="notion-3731d46c18fc80f4abead602c013103b"></a>

### ❶  `*`(역참조 변수) ➡️ L-value, R-value 둘 다 가능\! (O)

포인터 앞에 `*`를 붙인 `*p`는 주소문을 열고 들어간 "실제 원본 변수의 메모리 공간"을 의미하기 때문에 둘 다 가능합니다.

```c
int a = 10;
int b = 0;
int* p = &a;

*p = 20;   // [L-value 사용] a의 메모리 공간에 20을 집어넣음 (좌변)
b = *p;    // [R-value 사용] a 공간에 있던 값(20)을 꺼내서 b에 대입 (우변)
```

<a id="notion-3731d46c18fc807b8eede15297e3c022"></a>

### ❷ `&` (주소 연산자) ➡️ 오직 R-value만 가능\! (O)

변수의 주소를 구한 결과(예: `&a`)는 컴퓨터가 그 순간 계산해 낸 임시 숫자(주소 상수 값)일 뿐입니다. 이 주소 숫자 자체가 값을 담을 수 있는 변수 공간은 아니기 때문에 좌변에 올 수 없습니다.

```c
int a = 10;
int* p;

p = &a;    // [R-value 사용] 주소값 '100번지'라는 숫자를 p에 대입 (우변)
&a = 500;  // [오류! L-value 불가능] "100번지라는 숫자 자체에 500을 대입하라"가 되므로 컴파일 에러!
```

<a id="notion-3731d46c18fc80acb436d9f8c11ea22a"></a>

### 💡 노션 복습용 최종 확장판 요약

> \*\*`L-value`\*\*는 실제 주소가 있는 \*\*지속적인 메모리 공간(좌변 가능)\*\*이고, \*\*`R-value`\*\*는 쓰고 사라지는 \*\*임시 값(우변만 가능)\*\*이다.\*\*`*p`\*\*는 주소로 찾아간 **실제 변수 공간**이므로 **L-value와 R-value 모두** 쓰일 수 있다.\*\*`&a`\*\*는 임시로 계산된 \*\*주소 숫자(상수)\*\*일 뿐이므로 **오직 R-value로만** 쓰일 수 있다.

<br>

**\[배열과 포인터\]**

<a id="notion-3731d46c18fc80508296cfc3b805cfae"></a>

### 1\. 배열명은 첫 번째 요소의 주소다.

- **예시:** `arr`이라는 이름만 단독으로 쓰면 `&arr[0]`과 완벽히 똑같은 **1000번지**입니다.

```c
int arr[3] = {10, 20, 30};

printf("%p\n", arr);        // 출력: 1000 (시작 주소)
printf("%p\n", &arr[0]);     // 출력: 1000 (0번 방의 주소로 동일)
```

<a id="notion-3731d46c18fc801ca548e48a6ffcbf55"></a>

### 2\. 포인터에 배열명을 저장하면 포인터를 배열명처럼 사용할 수 있다.

- **예시:** 포인터 변수 `p`에 `arr`을 대입하면, 대괄호(`[]`)를 붙여 **`p[1]`** 같은 배열 문법을 그대로 쓸 수 있습니다.

```c
int arr[3] = {10, 20, 30};
int* p = arr;               // 포인터에 배열 이름(주소)을 저장

printf("%d\n", p[1]);       // 출력: 20 (arr[1]과 똑같이 동작함)
```

<a id="notion-3731d46c18fc8004b7e6c219b7a2bb10"></a>

### 3\. 배열명의 정수 덧셈은 가리키는 자료형의 크기를 곱해서 더한다.

- **예시:** `int`형은 4바이트이므로, 주소에 `1`을 더하면 실제 메모리 번지는 **4바이트**가 더해진 1004번지가 됩니다.

```c
int arr[3] = {10, 20, 30};

// 주소 계산 공식: 시작 주소(1000) + (정수 1 * int 크기 4바이트) = 1004번지
printf("%p\n", arr + 1);    // 출력: 1004
printf("%d\n", *(arr + 1)); // 출력: 20 (1004번지에 사는 값)
```

<a id="notion-3731d46c18fc804dbae7dcbeda3df22f"></a>

### 4\. 포인터의 뺄셈 결과는 배열 요소 간의 간격 차이를 의미한다.

- **예시:** 2번 방 주소(1008번지)에서 0번 방 주소(1000번지)를 빼면, 바이트 차이(8)가 아니라 "몇 칸 떨어져 있는가(2)"가 나옵니다.

```c
int arr[3] = {10, 20, 30};
int* p2 = &arr[2];          // 2번 방 주소 (1008번지)
int* p0 = &arr[0];          // 0번 방 주소 (1000번지)

// 간격 계산 공식: (1008 - 1000) / int 크기 4바이트 = 2칸
printf("%d\n", p2 - p0);    // 출력: 2 (두 포인터 사이에 방이 2개 차이 난다는 뜻)
```

<a id="notion-3731d46c18fc808fa9bddc4ce2cc18bf"></a>

### 💡 요약

```c
1. arr == &arr[0]
2. p = arr  ->  p[i] == arr[i]
3. arr + n  ->  실제 주소 + (n * 자료형 크기)
4. ptr2 - ptr1 -> (실제 주소 차이) / 자료형 크기 == 방 개수 차이
```
