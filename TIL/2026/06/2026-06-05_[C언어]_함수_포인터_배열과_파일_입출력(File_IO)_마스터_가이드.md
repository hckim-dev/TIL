## 1\. 🗺️ 한눈에 보는 메모리 구동 원리

일반 포인터 배열이 메모리의 데이터(RAM) 주소를 가리킨다면, 함수 포인터 배열은 컴퓨터가 실행할 명령어들이 저장된 **코드(Code) 영역의 주소**를 가리킵니다.

- **원리:** 배열의 인덱스 번호(`[0]`, `[1]`, `[2]`)가 곧 함수 명세서 번호가 됩니다. `배열이름[인덱스](매개변수);` 기호 하나로 복잡한 분기문 없이 원하는 함수를 다이렉트 워프시켜 실행합니다.

<a id="notion-3761d46c18fc8030a94ee6b0b00041fd"></a>

## 2\. 💻 함수 포인터 배열 공식 가이드

함수 포인터 배열을 선언할 때는 묶으려는 함수들의 "리턴 타입"과 "매개변수 형태"가 완벽하게 일치해야 체인으로 묶을 수 있습니다.

```c
// 💡 기본 공식: 리턴타입 (*배열이름[]) (매개변수타입1, 매개변수타입2...)

// 예시: 리턴이 void이고, 인자로 (Account_t*, int*)를 받는 함수들의 배열
void (*menu_funcs[])(Account_t*, int*) = {
    create_account,       // index 0
    deposit,              // index 1
    withdraw,             // index 2
    display_all_accounts  // index 3
};
```

<a id="notion-3761d46c18fc801d8dd6f04f50005447"></a>

### ⚠️ 주의할 점 (괄호의 중요성)

- `void (*menu_funcs[])()` : **함수 포인터들의 배열** (우리가 원하는 것 ⭕)
- `void *menu_funcs[]()` : 주소(`void*`)를 리턴하는 일반 함수들의 배열 (완전 오작동 ❌)

<a id="notion-3761d46c18fc8085b681c907a23ae769"></a>

## 🛠️ 3. switch문 vs 함수 포인터 배열 구조 비교

메뉴 분기 처리를 할 때 두 방식의 코드 다이어트 차이입니다.

<a id="notion-3761d46c18fc804ab87bf1855da5522f"></a>

### 🧱 과거: `switch~case` 방식 (늘어지는 코드)

```c
switch (choice) {
    case 1: create_account(acc, &count); break;
    case 2: deposit(acc, &count); break;
    case 3: withdraw(acc, &count); break;
    case 4: display_all_accounts(acc, &count); break;
}
```

<a id="notion-3761d46c18fc808b81a5c3a836ba73de"></a>

### 💎 진화: 함수 포인터 배열 방식 (단 한 줄)

```c
// 인덱스 범위 예외 처리만 앞에 해두면 단 한 줄로 깔끔하게 끝납니다.
menu_funcs[choice - 1](acc, &count);
```

<a id="notion-3761d46c18fc80b29d2ee87042967e3d"></a>

## 📊 함수 포인터 배열의 장단점 요약표

|  |  |
| --- | --- |
| **👍 장점 (장착해야 하는 이유)** | **👎 단점 및 주의점** |
| **압도적인 가독성:** 수백 줄짜리 `switch` 문을 단 한 줄로 축약 | **엄격한 규칙:** 묶으려는 함수들의 리턴형/매개변수가 똑같아야 함 |
| **O(1)의 고속 분기:** 순차 대조가 아닌 주소 다이렉트 점프 연산 | **가독성 난해:** 초보 개발자가 처음 볼 때 문법이 어려워 보임 |
| **확장성 업:** 메뉴가 추가되어도 `main` 로직 수정 없이 배열만 확장 | **인덱스 오버플로우:** 잘못된 인덱스 참조 시 팅김 위험 (예외처리 필수) |

<a id="notion-3761d46c18fc809eb66bcfee64e0fc0e"></a>

### 📋 한 줄 요약

> **함수 포인터 배열**은 동일한 규격(리턴형, 매개변수)을 가진 함수들의 주소를 모아놓은 \*\*'함수 실행 테이블'\*\*이며, 이를 활용하면 복잡하고 거대한 `switch~case` 분기문을 지워버리고 **단 한 줄의 인덱스 참조만으로 함수를 초고속 호출**하는 고급 아키텍처를 구현할 수 있다\!

## 1\. fopen (File Open) : 파일 열기

파일을 사용하기 위해 운영체제로부터 파일의 주소록(스트림 포인터)을 얻어오는 함수입니다.

<a id="notion-3761d46c18fc805dbcd6f886151bd805"></a>

### 📌 함수 원형

```c
FILE* fopen(const char* filename, const char* mode);
```

- **반환값:** 성공 시 파일의 주소를 가리키는 `FILE*` 포인터 반환, 실패 시 `NULL` 반환.
- **사용 예시:**

```c
FILE* fp = fopen("test.txt", "w");
if (fp == NULL) {
    printf("파일 열기 실패!\n");
}
```

<a id="notion-3761d46c18fc80bdad74ca0af1f313ea"></a>

### 📌 가장 많이 쓰는 파일 모드 (Mode) 주주 정리

|  |  |  |  |
| --- | --- | --- | --- |
| **모드** | **의미** | **파일이 없을 때** | **파일이 이미 있을 때** |
| **`"r"`** (Read) | 읽기 전용 | <strong>에러 발생 (</strong><strong>`NULL`</strong> <strong>반환)</strong> | 파일의 처음부터 읽음 |
| **`"w"`** (Write) | 쓰기 전용 | **새로 생성** | **기존 내용 전부 삭제 (덮어쓰기)** |
| **`"a"`** (Append) | 이어 쓰기 | **새로 생성** | 기존 내용 뒤에 이어서 작성 |

> 💡 **바이너리 파일(이미지, 데이터 등)을 다룰 때 팁**
>
> 텍스트 파일이 아닌 이진 데이터를 다룰 때는 뒤에 `b`를 붙여줍니다. (예: `"rb"`, `"wb"`, `"ab"`)

<a id="notion-3761d46c18fc800fa898cb4b65156e52"></a>

## 2\. fclose (File Close) : 파일 닫기

사용이 끝난 파일의 연결을 끊고, 메모리 버퍼를 완전히 비우는 함수입니다.

<a id="notion-3761d46c18fc8028ae29e05e58fc72e7"></a>

### 📌 함수 원형

```c
int fclose(FILE* stream);
```

- **반환값:** 성공 시 `0` 반환, 실패 시 `EOF`(-1) 반환.
- **사용 예시:**

```c
fclose(fp);
```

<a id="notion-3761d46c18fc801797cee78af185a6b2"></a>

### 📌 닫지 않으면(fclose를 안 하면) 생기는 문제점

1. **데이터 유실:** 파일에 글을 쓸 때, 프로그램은 즉시 하드디스크에 저장하지 않고 임시 메모리(버퍼)에 모아둡니다. `fclose`를 해야 이 버퍼가 파일로 완전히 물리적 저장이 되는데, 안 닫고 강제 종료되면 내용이 날아갈 수 있습니다.
2. **메모리 누수 (Resource Leak):** 파일 포인터가 차지하는 시스템 자원이 계속 낭비됩니다.
3. **파일 잠김:** 프로그램이 켜져 있는 동안 다른 프로그램에서 해당 파일을 수정하거나 지우지 못하게 잠겨버릴 수 있습니다.

<a id="notion-3761d46c18fc8035bd52dd35441ee677"></a>

## 📝 한 줄 요약

- `fopen`은 파일을 여는 함수이며, <strong>실패할 확률(</strong><strong>`NULL`</strong><strong>)이 있으므로 항상 예외 처리가 필요하다.</strong>
- `fclose`는 버퍼를 비우고 자원을 반환하는 함수이며, <strong>`fopen`</strong>**을 했다면 반드시 세트로 작성해야 한다.**
- 텍스트는 `"r", "w", "a"`, 바이너리는 `"rb", "wb", "ab"`를 쓴다.

## 1\. fgetc (File Get Character) : 파일에서 한 글자 읽기

파일 포인터가 가리키는 위치에서 **문자 딱 하나**를 읽어오고, 파일 포인터의 위치를 자동으로 다음 문자로 1칸 이동시킵니다.

<a id="notion-3761d46c18fc80a89c4ee7538de6d1ce"></a>

### 📌 함수 원형

```c
int fgetc(FILE* stream);
```

- **반환값:** \* 성공 시: 읽어온 문자(ASCII 코드 값)를 반환합니다.

  - 실패 시 또는 파일 끝(`EOF`)에 도달 시: `EOF` (-1)를 반환합니다.
- **특이점 (중요):** 반환 타입이 `char`가 아니라 `int`입니다. 파일의 끝을 알리는 `EOF` 값이 `1`이기 때문에, 이를 정확하게 표현하고 처리하기 위해서 `int`형으로 반환합니다.

<a id="notion-3761d46c18fc80f68496e41e6e357989"></a>

### 📌 사용 예시 (파일 끝까지 한 글자씩 읽어 출력하기)

```c
int ch; // EOF(-1)를 받기 위해 int형으로 선언
FILE* fp = fopen("test.txt", "r");

if (fp != NULL) {
    // 파일 끝(EOF)을 만날 때까지 무한 반복하며 한 글자씩 읽음
    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch); // 읽어온 한 글자를 화면에 출력
    }
    fclose(fp);
}
```

<a id="notion-3761d46c18fc8009b536f29a836ab56f"></a>

## 2\. fputc (File Put Character) : 파일에 한 글자 쓰기

파일 포인터가 가리키는 위치에 **문자 딱 하나**를 집어넣고, 포인터를 1칸 이동시킵니다.

<a id="notion-3761d46c18fc800eb6e9cea1b212fc86"></a>

### 📌 함수 원형

```c
int fputc(int character, FILE* stream);
```

- **매개변수:**

  - `character`: 파일에 쓸 문자 (내부적으로는 ASCII 정수값으로 전달됨).
  - `stream`: 쓰고자 하는 파일의 포인터.
- **반환값:** \* 성공 시: 방금 **쓴 문자**를 그대로 반환합니다.

  - 실패 시: `EOF` (-1)를 반환합니다.

<a id="notion-3761d46c18fc80aa8627e3dd57b5b2e4"></a>

### 📌 사용 예시 (파일에 'A'부터 'Z'까지 쓰기)

```c
FILE* fp = fopen("alphabet.txt", "w");

if (fp != NULL) {
    // 'A'부터 'Z'까지 한 글자씩 파일에 기록
    for (char ch = 'A'; ch <= 'Z'; ch++) {
        fputc(ch, fp);
    }
    fclose(fp); // 결과 파일 내용: ABCDEFGHIJKLMNOPQRSTUVWXYZ
}
```

<a id="notion-3761d46c18fc80d6a6c5daf7c78ace50"></a>

## 📝 한 줄 요약

- `fgetc`와 `fputc`는 파일 입출력 함수 중 가장 지름길인 "1바이트(한 글자) 전용 통로"이다.
- `fgetc`는 파일의 끝에 도달하면 `EOF`(-1)를 반환하므로, 받아주는 변수는 `char`가 아니라 반드시 <strong>`int`</strong>**형**으로 선언해야 안전하다.
- 함수 이름 뒤의 `c`는 Character(문자)를 뜻한다\! (`fgetc` = File Get Character / `fputc` = File Put Character)

## 1\. 개방 모드 (File Open Mode)

`fopen` 함수를 사용할 때 파일의 사용 목적을 지정하는 문자열입니다. 기본 모드(`r`, `w`, `a`)에 기능이 추가되는 형태로 기억하시면 쉽습니다.

- **`r`** <strong>(Read):</strong> 읽기 전용. 파일이 없으면 에러(`NULL`)가 발생합니다.
- **`w`** <strong>(Write):</strong> 쓰기 전용. 파일이 없으면 만들고, **이미 있으면 내용이 싹 지워진 채**로 새로 씁니다.
- **`a`** <strong>(Append):</strong> 이어 쓰기. 파일이 없으면 만들고, 있으면 **기존 내용 맨 뒤에** 이어서 씁니다.

<a id="notion-3761d46c18fc80dd8e8dd16b86ba5905"></a>

### ➕ 확장 모드 (더 정밀한 제어)

- **`+`** <strong>(수정 모드):</strong> 읽기와 쓰기를 **동시에** 가능하게 만듭니다.

  - `r+`: 읽기/쓰기 모드 (파일이 필수, 기존 내용 유지하며 덮어씀)
  - `w+`: 읽기/쓰기 모드 (파일이 없으면 생성, 있으면 기존 내용 삭제)
  - `a+`: 읽기/이어쓰기 모드 (파일이 없으면 생성, 읽기는 가능하되 쓰기는 무조건 맨 뒤에 추가)
- **`b`** <strong>(바이너리 모드):</strong> 이미지, 구조체, 실행 파일 등 이진 데이터를 다룰 때 붙입니다.

  - 예: `rb`, `wb`, `rb+` (앞서 작성했던 계좌 프로그램에서 구조체를 저장할 때 사용한 방식입니다.)

<a id="notion-3761d46c18fc8034915cf03ff6d5f82f"></a>

## 2\. fseek : 파일 포인터 위치 마음대로 이동하기

파일을 읽거나 쓸 때, 현재 위치(Cursor)를 내가 원하는 바이트 수만큼 강제로 이동시키는 함수입니다.

<a id="notion-3761d46c18fc80d0975accc9d416ccd5"></a>

### 📌 함수 원형

```c
int fseek(FILE* stream, long offset, int origin);
```

- **`offset`** <strong>(이동 거리):</strong> 몇 바이트 이동할지 결정합니다. 양수(`+`)면 오른쪽(뒤로), 음수()면 왼쪽(앞으로) 이동합니다.
- **`origin`** <strong>(기준점):</strong> 어디를 기준으로 움직일지 결정하는 세 가지 상수입니다.

  - `SEEK_SET`: **파일의 맨 처음**을 기준으로 이동
  - `SEEK_CUR`: **현재 위치**를 기준으로 이동
  - `SEEK_END`: **파일의 맨 끝**을 기준으로 이동

<a id="notion-3761d46c18fc80dbafdac2e96ef489c3"></a>

### 📌 사용 예시

```c
fseek(fp, 0, SEEK_END);      // 파일의 맨 끝으로 이동 (파일 크기 잴 때 많이 씀)
fseek(fp, -10, SEEK_CUR);    // 현재 위치에서 앞으로(왼쪽으로) 10바이트 이동
fseek(fp, sizeof(int), SEEK_SET); // 맨 처음에서 int 크기만큼 뒤로 이동
```

<a id="notion-3761d46c18fc8022986be2b599a3593a"></a>

## 3\. rewind : 파일 포인터를 맨 처음으로 리셋

말 그대로 비디오테이프를 뒤로 감듯, 파일 포인터를 **파일의 맨 첫 번째 위치로 되돌리는** 함수입니다.

<a id="notion-3761d46c18fc80dca0d5e7ca9d0c3e0f"></a>

### 📌 함수 원형

```c
void rewind(FILE* stream);
```

- `fseek(fp, 0, SEEK_SET);`을 수행한 것과 **완벽하게 동일하게 동작**합니다.
- 파일에 데이터를 다 쓰고 나서 처음부터 다시 읽어야 할 때 아주 자주 쓰이며, 코드가 직관적이어서 자주 애용됩니다.

<a id="notion-3761d46c18fc8008963bd30d9fb55d3b"></a>

## 4\. feof : 파일의 끝(End Of File) 체크하기

현재 파일 포인터가 파일의 맨 끝(더 이상 읽을 데이터가 없는 곳)에 도달했는지 확인하는 함수입니다.

<a id="notion-3761d46c18fc805f98dff5e6cb85a58d"></a>

### 📌 함수 원형

```c
int feof(FILE* stream);
```

- **반환값:** 아직 끝이 아니면 <strong>`0`</strong>, 파일의 끝에 도달했으면 `0이 아닌 값(참)`을 반환합니다.

<a id="notion-3761d46c18fc80f0936cc9a6f0228212"></a>

### ⚠️ 주의점 (가장 많이 하는 실수\!)

`feof`는 파일 끝을 미리 예측하는 함수가 아닙니다. "이미 파일 끝을 지나쳐서 읽으려고 시도했다가 실패한 적이 있는가?"를 물어보는 함수입니다.

따라서 아래와 같이 작성하면 마지막 데이터가 두 번 출력되는 버그가 생길 수 있습니다.

```c
// ❌ 잘못된 예시 (마지막 글자가 두 번 찍힐 위험 있음)
while(!feof(fp)) {
    ch = fgetc(fp);
    printf("%c", ch);
}

// ⭕ 올바른 예시 (읽기 시도를 먼저 하고 성공 여부를 체크)
while(1) {
    ch = fgetc(fp);
    if(feof(fp)) break; // 읽어봤더니 끝이었으면 탈출!
    printf("%c", ch);
}
```

<a id="notion-3761d46c18fc80669333ee3f6ace1cd6"></a>

## 📝 한 줄 요약노트

1. **개방모드:** `r`(읽기), `w`(기존 삭제 쓰기), `a`(이어 쓰기), `+`(읽기쓰기 겸용), `b`(바이너리).
2. **fseek:** 기준점(`SEEK_SET/CUR/END`)으로부터 원하는 바이트(`offset`)만큼 이동.
3. **rewind:** 포인터를 맨 앞으로 순간이동 시키기 (`fseek` 맨 처음 기준 0 이동과 동일).
4. **feof:** 파일 끝을 읽다가 헛디뎠을 때 참(0이 아닌 값)을 반환하는 종료 판독기.

## 1\. fgets (File Get String) : 파일에서 문자열(한 줄) 읽기

파일에서 지정한 크기만큼, 혹은 줄 바꿈 문자(`\n`)를 만날 때까지 문자열을 읽어오는 함수입니다.

<a id="notion-3761d46c18fc80259faee640352eec57"></a>

### 📌 함수 원형

```c
char* fgets(char* str, int num, FILE* stream);
```

- **매개변수:**

  - `str`: 파일에서 읽어온 문자열을 저장할 배열(버퍼)의 주소.
  - `num`: **최대 몇 바이트까지 읽을 것인지** 지정하는 크기 (보통 배열의 크기를 넣음).
  - `stream`: 읽어올 파일 포인터.
- **반환값:** 성공 시 문자열이 저장된 `str` 주소 반환, 파일 끝(`EOF`)이거나 실패 시 `NULL` 반환.

<a id="notion-3761d46c18fc80f39feeddc90cc344f4"></a>

### ⚠️ 아주 중요한 특징 (시험 단골 주제)

1. <strong>`num - 1`</strong>**개만 읽는다:** `fgets`는 문자열의 안전을 위해 내가 지정한 크기보다 **무조건 1바이트 적게** 읽습니다. 그리고 맨 마지막 자리에 문자열의 끝을 알리는 널 문자(`'\0'`)를 자동으로 채워 넣습니다.
2. <strong>줄 바꿈(</strong><strong>`\n`</strong><strong>)을 포함한다:</strong> 엔터(줄 바꿈)를 만나면 읽기를 멈추는데, 이때 <strong>`\n`</strong>**까지 포함해서** 배열에 저장합니다.

<a id="notion-3761d46c18fc801a9c85dd8737cfd049"></a>

### 📌 사용 예시 (파일 내용을 한 줄씩 끝까지 읽기)

```c
char buffer[100]; // 한 줄을 담을 바구니
FILE* fp = fopen("test.txt", "r");

if (fp != NULL) {
    // 파일 끝(NULL이 반환될 때)까지 한 줄씩 계속 읽음
    while (fgets(buffer, sizeof(buffer), fp) != NULL) {
        printf("%s", buffer); // buffer 안에 \n이 포함되어 있어 자동으로 줄바꿈됨
    }
    fclose(fp);
}
```

<a id="notion-3761d46c18fc8071b85ff9c907eafb24"></a>

## 2\. fputs (File Put String) : 파일에 문자열 쓰기

메모리에 있는 문자열을 파일에 통째로 집어넣는 함수입니다.

<a id="notion-3761d46c18fc807d99e8c1ee5a0bd5c6"></a>

### 📌 함수 원형

```c
int fputs(const char* str, FILE* stream);
```

- **매개변수:**

  - `str`: 파일에 기록할 문자열의 주소 (끝에 `'\0'`이 있는 정상적인 문자열이어야 함).
  - `stream`: 저장할 파일 포인터.
- **반환값:** 성공 시 음수가 아닌 값 반환, 실패 시 `EOF`(-1) 반환.

<a id="notion-3761d46c18fc801e9aaac3bfc9700c50"></a>

### ⚠️ `puts` 함수와의 차이점 (주의\!)

콘솔 창에 출력하는 기본 `puts("Hello");` 함수는 자동으로 뒤에 줄 바꿈(`\n`)을 붙여주지만, 파일 전용인 <strong>`fputs`</strong>**는 줄 바꿈을 자동으로 해주지 않습니다.** 문자열에 있는 그대로 딱 글자만 파일에 밀어 넣기 때문에, 줄을 바꾸고 싶다면 문자열 뒤에 직접 `\n`을 적어주어야 합니다.

<a id="notion-3761d46c18fc804db016d1afef75c77f"></a>

### 📌 사용 예시 (파일에 두 줄 쓰기)

```c
FILE* fp = fopen("output.txt", "w");

if (fp != NULL) {
    // fputs는 자동으로 줄바꿈을 안 해주므로 \n을 직접 붙여야 함
    fputs("Hello World!\n", fp);
    fputs("C Programming is fun.\n", fp);

    fclose(fp);
}
```

<a id="notion-3761d46c18fc804bb1fdde05b9826c6b"></a>

## 📝 fgetc/fputc vs fgets/fputs 한눈에 비교

|  |  |  |  |
| --- | --- | --- | --- |
| **함수 세트** | **대상** | **특징** | **주요 용도** |
| **`fgetc / fputc`** | **문자** (1바이트) | `int`형 데이터 취급, `EOF` 검사가 직관적 | 파일 복사, 암호화, 데이터 파싱 |
| **`fgets / fputs`** | **문자열** (한 줄) | 널 문자(`\0`) 자동 처리, 크기 제한으로 **안전함** | 텍스트 파일 읽기, 로그 기록 |

> **💡 면접/시험용 추가 팁\!**
>
> 옛날에 쓰던 `gets()` 함수는 크기 제한이 없어서 해킹(버퍼 오버플로우)에 취약해 C언어 표준에서 퇴출당했습니다. 그래서 현재 C언어에서 키보드로 안전하게 문자열을 입력받을 때도 표준 입력 스트림(`stdin`)을 결합한 \*\*`fgets(buf, sizeof(buf), stdin);`\*\*을 쓰는 것이 정석입니다\!

## 1\. fprintf (File Print Formatted) : 서식을 지정하여 파일에 쓰기

화면에 출력하던 `printf`와 사용법이 99% 똑같습니다. 단지 첫 번째 매개변수로 "어떤 파일에 쓸 것인가"에 대한 파일 포인터(`FILE*`)만 추가해 주면 됩니다.

<a id="notion-3761d46c18fc80aa953af7b99258ec74"></a>

### 📌 함수 원형

```c
int fprintf(FILE* stream, const char* format, ...);
```

- <strong>사용 예시:</strong>C

  ```c
  int age = 25;
  double height = 175.5;
  char name[] = "홍길동";

  FILE* fp = fopen("info.txt", "w");
  if (fp != NULL) {
      // printf와 똑같은데 맨 앞에 fp만 붙여주면 파일로 들어갑니다!
      fprintf(fp, "이름: %s, 나이: %d, 키: %.1f\n", name, age, height);
      fclose(fp);
  }
  ```

<a id="notion-3761d46c18fc80968a1ae0d1a259e45e"></a>

## 2\. fscanf (File Scan Formatted) : 서식을 지정하여 파일에서 읽기

이것 역시 키보드로 입력받던 `scanf`와 완전히 똑같습니다. 파일에서 데이터를 읽어와 지정한 포맷대로 분석하여 변수에 쏙쏙 나누어 담아줍니다.

<a id="notion-3761d46c18fc809f849de029ab45ce0c"></a>

### 📌 함수 원형

```c
int fscanf(FILE* stream, const char* format, ...);
```

- **반환값 (중요):** 성공적으로 읽어서 변수에 대입한 **항목의 개수**를 반환합니다. 만약 파일 끝에 도달하면 `EOF`(-1)를 반환합니다.
- **사용 예시:**

  ```c
  int age;
  double height;
  char name[20];

  FILE* fp = fopen("data.txt", "r"); // 파일 내용이 "이순신 30 182.3" 일 때
  if (fp != NULL) {
      // 파일에서 문자열, 정수, 실수를 순서대로 읽어 변수에 주소(&)로 채워 넣음
      // fscanf는 공백(스페이스, 탭, 엔터)을 기준으로 데이터를 구별합니다.
      fscanf(fp, "%s %d %lf", name, &age, &height);

      printf("읽어온 값: %s, %d, %.1f\n", name, age, height);
      fclose(fp);
  }
  ```

<a id="notion-3761d46c18fc80ee8ae2fb3224af6d11"></a>

### ⚠️ fscanf 사용 시 필수 주의점\! (시험/과제 단골 버그)

`fscanf`는 `feof` 함수와 마찬가지로 파일 끝을 처리할 때 주의해야 합니다. 파일 끝까지 모든 데이터를 안전하게 읽어오려면 <strong>반환값이</strong> <strong>`EOF`</strong>**가 아닐 때까지 반복**하도록 조건문을 짜는 것이 가장 완벽합니다.

```c
// ⭕ 파일 끝까지 안전하게 구조화된 데이터를 읽어오는 모범 답안
while (fscanf(fp, "%s %d %lf", name, &age, &height) != EOF) {
    printf("%s님의 나이는 %d세입니다.\n", name, age);
}
```

<a id="notion-3761d46c18fc80d7a529c687af2b235f"></a>

## 💡 한눈에 보는 형제 함수 매핑 테이블

이 구조를 머릿속에 넣어두면 굳이 외우지 않아도 함수를 자유자재로 쓸 수 있습니다. 사실 `printf`와 `scanf`는 `fprintf`, `fscanf`에 콘솔 주소(`stdout`, `stdin`)를 매칭해둔 특수 형태일 뿐입니다\!

|  |  |  |  |
| --- | --- | --- | --- |
| **대상 장치** | **출력 함수 (쓰기)** | **입력 함수 (읽기)** | **특징** |
| **콘솔 (화면/키보드)** | `printf(...)` | `scanf(...)` | 우리가 아는 기본 함수 |
| **모든 스트림 (파일 등)** | `fprintf(fp, ...)` | `fscanf(fp, ...)` | 맨 앞에 파일 주소(`fp`)만 추가 |
| **콘솔을 변형한 형태** | `fprintf(stdout, ...)` | `fscanf(stdin, ...)` | `printf`, `scanf`와 완전 동일하게 작동 |

<a id="notion-3761d46c18fc80b4b870e7b8d457cff6"></a>

## 📝 3초 요약 노트

- `fprintf`와 `fscanf`는 <strong>`printf`</strong><strong>/</strong><strong>`scanf`</strong>**와 사용법이 쌍둥이처럼 똑같다.** \* 차이점은 맨 첫 번째 인자로 데이터를 밀어 넣거나 꺼내올 <strong>`FILE* fp`</strong><strong>(파일 포인터)를 적어준다는 것</strong>뿐이다.
- 정수, 실수, 문자열이 섞여 있는 **텍스트 형태의 데이터 베이스(CSV 형식 등)를 다룰 때 최강의 효율**을 자랑한다.

## 1\. fflush (File Flush) : 버퍼 비우기

<a id="notion-3761d46c18fc8037a135ed69b35c33cc"></a>

### 📌 함수 원형

```c
int fflush(FILE* stream);
```

- **반환값:** 성공 시 `0` 반환, 실패 시 `EOF`(-1) 반환.
- **사용 예시:**

  ```c
  FILE* fp = fopen("log.txt", "w");
  fprintf(fp, "시스템 정상 작동 중...");

  fflush(fp); // 파일이 아직 닫히지 않았지만, "시스템 정상 작동 중..."이라는 글자를 즉시 디스크에 저장함!
  ```

<a id="notion-3761d46c18fc807f9ac1eee657fcdb09"></a>

## 2\. fflush는 언제, 왜 쓸까요?

<a id="notion-3761d46c18fc8009ba0fe007949de6bc"></a>

### ① 프로그램이 갑자기 다운될 때를 대비 (데이터 안전성)

은행 프로그램이나 24시간 돌아가는 서버 프로그램을 짠다고 가정해 볼게요. `fprintf`로 로그나 거래 내역을 열심히 썼는데, 아직 버퍼에만 남아있고 실제 하드디스크 파일에는 저장이 안 된 상태에서 컴퓨터 전원이 툭 꺼지거나 프로그램이 팅기면 데이터가 날아갑니다.

이때 중간중간 `fflush(fp);`를 해주면 **그 시점까지의 데이터가 안전하게 파일에 물리적으로 기록**됩니다.

<a id="notion-3761d46c18fc8088a0fdc515bdc865f8"></a>

### ② 실시간으로 데이터를 확인해야 할 때

`fclose(fp);`를 호출하면 내부적으로 `fflush`가 자동으로 실행되면서 파일이 완전히 저장되고 닫힙니다. 하지만 파일을 닫지 않고 **계속 열어둔 상태에서 실시간으로 다른 프로그램이 이 파일을 읽어야 할 때**가 있습니다. 그때 `fflush`를 쓰면 파일을 닫지 않고도 데이터를 바로바로 업데이트해 줄 수 있습니다.

<a id="notion-3761d46c18fc80a9b849fe85213f9f76"></a>

## ⚠️ C언어 표준에서 주의할 점 (출제 단골)

가끔 옛날 책이나 인터넷 글을 보면 키보드 입력 버퍼를 비우려고 `fflush(stdin);`을 쓰는 코드가 보입니다.

- <strong>출력 스트림 비우기 (</strong><strong>`fflush(fp)`</strong><strong>,</strong> <strong>`fflush(stdout)`</strong><strong>):</strong> C언어 표준에서 **정상 작동**합니다. 버퍼의 내용을 파일이나 화면으로 보냅니다.
- <strong>입력 스트림 비우기 (</strong><strong>`fflush(stdin)`</strong><strong>):</strong> C언어 표준 규칙상 정의되지 않은 행동(Undefined Behavior)입니다. 일부 컴파일러(과거 비주얼 스튜디오 등)에서는 편의상 작동하기도 했지만, 최신 컴파일러나 리눅스(GCC) 환경에서는 작동하지 않고 에러나 버그를 유발합니다.

> 💡 **그럼 키보드 입력 버퍼는 어떻게 비우나요?**
>
> 앞서 리팩터링 코드에서도 사용했듯이, `while (getchar() != '\n');` 같은 반복문을 사용해 엔터키가 나올 때까지 버퍼를 한 글자씩 수동으로 읽어서 지워주는 것이 표준적이고 가장 안전한 방법입니다.

<a id="notion-3761d46c18fc80ea835ced0f1b45e5e2"></a>

## 📝 3초 요약 노트

- `fflush`는 스트림의 **임시 창고(버퍼)에 쌓여있는 데이터를 목적지(파일)로 즉시 전송**시키는 함수이다.
- <strong>`fclose`</strong>**를 하면 자동으로 수행**되지만, 파일을 닫지 않고 데이터를 실시간으로 안전하게 저장하고 싶을 때 수동으로 호출한다.
- 오직 **출력(Write) 스트림**에만 사용하는 것이 원칙이다\! (입력 버퍼를 비우는 용도로 쓰면 안 됨)

<br>

<a id="notion-3761d46c18fc80d99c6aca7ce2fa0a63"></a>

## 1\. fwrite (File Write) : 메모리 데이터를 파일에 통째로 쓰기

변수나 배열, 구조체 등 메모리에 들어있는 데이터를 **크기(Byte)와 개수만큼 통째로 복사해서 파일에 저장**합니다.

<a id="notion-3761d46c18fc804aafe5f62fc8fa2ed3"></a>

### 📌 함수 원형

```c
size_t fwrite(const void* ptr, size_t size, size_t count, FILE* stream);
```

- <strong>`ptr`</strong><strong>:</strong> 파일에 저장할 데이터가 있는 <strong>메모리의 주소(포인터)</strong>.
- <strong>`size`</strong><strong>:</strong> 데이터 **하나의 크기** (주로 `sizeof(타입)` 형태로 씀).
- <strong>`count`</strong><strong>:</strong> 그 데이터를 **몇 개** 저장할 것인가.
- <strong>`stream`</strong><strong>:</strong> 저장할 파일 포인터.
- **반환값:** 실제로 파일에 성공적으로 쓴 **데이터의 개수** (`count`와 일치해야 정상).

<a id="notion-3761d46c18fc809292fec35273757bbf"></a>

### 📌 사용 예시 (구조체 변수 통째로 파일에 저장하기)

```c
typedef struct {
    int id;
    char name[20];
} Person;

Person p1 = {1, "홍길동"};
FILE* fp = fopen("person.dat", "wb"); // 바이너리 쓰기 모드

if (fp != NULL) {
    // p1의 주소(&p1)에서 시작해서, Person 구조체 크기만큼, 1개를, fp 파일에 써라!
    fwrite(&p1, sizeof(Person), 1, fp);
    fclose(fp);
}
```

<a id="notion-3761d46c18fc801998fdd7ac1e0fbf54"></a>

## 2\. fread (File Read) : 파일의 데이터를 메모리에 통째로 읽어오기

파일에 들어있는 이진 데이터를 있는 그대로 읽어서 **내가 지정한 메모리 공간(변수, 구조체, 배열 등)에 쏙 채워 넣는** 함수입니다.

<a id="notion-3761d46c18fc80628837c9d8fb89fa31"></a>

### 📌 함수 원형

```c
size_t fread(void* ptr, size_t size, size_t count, FILE* stream);
```

- <strong>`ptr`</strong><strong>:</strong> 파일에서 읽어온 데이터를 <strong>저장할 메모리의 주소(포인터)</strong>.
- <strong>`size`</strong><strong>:</strong> 읽어올 데이터 **하나의 크기**.
- <strong>`count`</strong><strong>:</strong> 데이터를 **몇 개** 읽어올 것인가.
- <strong>`stream`</strong><strong>:</strong> 읽어올 파일 포인터.
- **반환값:** 실제로 읽어오는 데 성공한 **데이터의 개수**. (만약 파일 끝에 도달하거나 에러가 나면 `count`보다 작은 값이 반환됨)

<a id="notion-3761d46c18fc807eb193fd538ab0a02e"></a>

### 📌 사용 예시 (파일에서 구조체 데이터 읽어오기)

```c
Person p2; // 데이터를 받아올 빈 바구니
FILE* fp = fopen("person.dat", "rb"); // 바이너리 읽기 모드

if (fp != NULL) {
    // fp 파일에서, Person 구조체 크기만큼, 1개를 읽어서, p2의 주소(&p2)에 채워라!
    size_t result = fread(&p2, sizeof(Person), 1, fp);

    if (result == 1) {
        printf("불러오기 성공! ID: %d, 이름: %s\n", p2.id, p2.name);
    }
    fclose(fp);
}
```

<a id="notion-3761d46c18fc8099a3ced1f92098bd99"></a>

## ⚠️ 중요: `fprintf / fscanf` vs `fwrite / fread` 차이점

이 둘의 차이를 명확히 아는 것이 파일 입출력 마스터의 핵심입니다.

- **`fprintf / fscanf`** <strong>(텍스트 입출력):</strong>

  - 사람이 읽을 수 있는 문자(텍스트) 형태로 바꾼 뒤 저장합니다.
  - 예를 들어 정수 `12345`를 저장하면 파일에는 문자 `'1'`, `'2'`, `'3'`, `'4'`, `'5'` 총 5바이트로 저장됩니다.
- **`fwrite / fread`** <strong>(바이너리 입출력):</strong>

  - 메모리에 있는 0과 1 상태 그대로 저장합니다.
  - 정수 `12345`를 저장하면 메모리 상의 정수 크기인 **4바이트** 그대로 파일에 박힙니다. 메모장으로 이 파일을 열면 글자가 다 깨져서 보이지만, **속도가 압도적으로 빠르고 용량이 최적화**됩니다.

<a id="notion-3761d46c18fc80b58535f5cbfe6888ac"></a>

## 📝 3초 요약 노트

- `fwrite`와 `fread`는 메모리에 있는 덩어리 데이터(구조체, 배열 등)를 형변환 없이 **통째로 파일과 주고받을 때 사용**한다.
- 매개변수 순서는 **`(메모리주소, 데이터하나의크기, 개수, 파일포인터)`** 세트이다.
- 반환값은 바이트 수가 아니라 성공한 '데이터 개수'를 반환하므로, 내가 요청한 개수(`count`)만큼 잘 읽고 썼는지 검사할 수 있다.
