## 공유 메모리(Shared Memory)

프로세스는 각각 **독립적인 가상 주소 공간**을 사용하므로 일반 변수는 서로 공유되지 않는다.

<a id="notion-3e41d46c18fc8081b01eee0fe9b1d09e"></a>

### 📝 시험

```text
부모 프로세스와 자식 프로세스가
일반 변수를 직접 공유할 수 있는가?

→ X
```

`fork()` 직후 변수 값은 같지만 각 프로세스의 주소 공간은 독립적이다.

공유 메모리는 여러 프로세스가 **동일한 메모리 영역을 자신의 주소 공간에 매핑하여 데이터를 공유**할 수 있게 하는 IPC 방식이다.

```text
Process A                  Process B
가상 주소 공간             가상 주소 공간
    │                          │
    └──── Shared Memory ───────┘
```

각 프로세스는 `shmat()`을 통해 공유 메모리를 자신의 가상 주소 공간에 연결한 뒤 일반 메모리처럼 접근한다.

# `shmget()` — 공유 메모리 생성/획득

```text
int shmget(key_t key, size_t size, int shmflg);
```

System V 공유 메모리 세그먼트를 생성하거나 기존 세그먼트를 얻는다.

<a id="notion-3e41d46c18fc800aa441fbf23109997f"></a>

### 매개변수

```text
key
→ 공유 메모리 식별용 Key

size
→ 공유 메모리 크기

shmflg
→ 권한 및 생성 옵션
   IPC_CREAT : 없으면 생성
```

예:

```text
id_shm = shmget(KEY_SHM,
                sizeof(struct shm_buf),
                0666 | IPC_CREAT);
```

<a id="notion-3e41d46c18fc80f989aac26dbf19c6bb"></a>

### 반환값

```text
성공 → Shared Memory ID
실패 → -1
```

<a id="notion-3e41d46c18fc806d8f50ee738b620945"></a>

### ⭐⭐⭐⭐⭐ 매우 중요

`shmget()`은 **공유 메모리 객체/세그먼트를 생성 → 공유 메모리는 물리 메모리에 생성됨**

System V IPC 정보는:

```text
ipcs
```

등으로 확인할 수 있다.

# `shmat()` — 공유 메모리 부착

```text
void *shmat(int shmid,
            const void *shmaddr,
            int shmflg);
```

공유 메모리를 **현재 프로세스의 가상 주소 공간에 연결(attach)** 한다.

<a id="notion-3e41d46c18fc80718952f6bc2ee676ca"></a>

### 매개변수

```text
shmid
→ shmget()으로 얻은 Shared Memory ID

shmaddr
→ 연결할 가상 주소
→ 일반적으로 NULL 사용
→ NULL이면 Kernel이 적절한 주소 선택

shmflg
→ 부착 옵션
```

예:

```text
shmbuf = shmat(id_shm, NULL, 0);
```

성공:

```text
공유 메모리가 연결된 주소 반환
```

실패:

```text
(void *)-1
```

연결 후에는:

```text
shmbuf->status
shmbuf->buf
shmbuf->cs
```

처럼 일반 구조체 포인터처럼 접근할 수 있다.

# `shmdt()` — 공유 메모리 분리

```text
int shmdt(const void *shmaddr);
```

현재 프로세스의 주소 공간에서 공유 메모리를 **분리(detach)** 한다.

```text
shmdt(shmbuf);
```

<a id="notion-3e41d46c18fc8061bf6cc1bdae7ca9cc"></a>

### 반환값

```text
성공 → 0
실패 → -1
```

<a id="notion-3e41d46c18fc801899c0ec5607755268"></a>

### ⭐⭐⭐ 중요

`shmdt()`는:

```text
프로세스와 공유 메모리 연결만 해제
```

하는 것이다.

즉:

```text
shmdt()
→ 공유 메모리 자체 삭제 X (물리 메모리 상에 그대로 남아 있음)
→ 현재 프로세스의 Mapping만 제거
```

다른 프로세스가 같은 공유 메모리를 계속 사용할 수도 있다.

# `shmctl()` — 공유 메모리 제어

```text
int shmctl(int shmid,
           int cmd,
           struct shmid_ds *buf);
```

공유 메모리의 정보를 확인하거나 삭제 등의 제어를 수행한다.

<a id="notion-3e41d46c18fc8040bf7afb86f9f64927"></a>

### 주요 매개변수

```text
shmid
→ Shared Memory ID

cmd
→ 수행할 명령

buf
→ 정보 입출력용 구조체
```

대표 명령:

```text
IPC_STAT
→ 공유 메모리 정보 획득

IPC_RMID
→ 공유 메모리 삭제 요청 // 중요 ★
```

예:

```text
shmctl(id_shm, IPC_STAT, &dsbuf);
```

→ 크기, 권한 등 정보 확인

```text
shmctl(id_shm, IPC_RMID, NULL);
```

→ 공유 메모리 제거 요청

<a id="notion-3e41d46c18fc80518983e6b139eb4ecd"></a>

### ⚠️ 중요

`IPC_RMID`를 호출했다고 현재 사용 중인 공유 메모리가 즉시 강제로 사라지는 것은 아니다.

```text
IPC_RMID
→ 삭제 대상으로 표시
→ 마지막 attach가 해제되면 실제 제거
```

# 공유 메모리 구조체 예제

```text
struct shm_buf
{
    int status;
    char buf[MAX_BUF];
    unsigned long cs;
};
```

공유 메모리 내부를 구조체 형태로 정의하면 여러 프로세스가 동일한 데이터 구조를 사용할 수 있다.

```text
status
→ 데이터 상태

buf
→ 실제 공유 데이터

cs
→ Checksum
```

# `shmput.c` — 공유 메모리 Writer

동작 흐름:

```text
shmget()
   ↓
공유 메모리 획득
   ↓
shmat()
   ↓
현재 프로세스 주소 공간에 부착
   ↓
공유 메모리에 시간 정보 Write
   ↓
Checksum 저장
   ↓
shmdt()
```

핵심:

```text
sprintf(shmbuf->buf, ...);
shmbuf->status = STATUS_VALID;
shmbuf->cs = cs;
```

Writer가 공유 메모리의 구조체를 직접 수정한다.

---

<a id="notion-3e41d46c18fc80d5b7e0d936827882f3"></a>

# `shmget.c` — 공유 메모리 Reader

동작 흐름:

```text
shmget()
   ↓
동일한 공유 메모리 획득
   ↓
shmat()
   ↓
공유 메모리 연결
   ↓
status 확인
   ↓
데이터 및 Checksum 확인
   ↓
shmdt()
```

Writer와 Reader가 같은:

```text
KEY_SHM
```

을 사용하므로 동일한 공유 메모리에 접근할 수 있다.

```text
shmput                  shmget
 Writer                 Reader
   │                       ▲
   │                       │
   └── Shared Memory ──────┘
```

# 공유 메모리의 특징

공유 메모리는 프로세스끼리 데이터를 복사해서 전달하는 방식이 아니라 **동일한 메모리 영역을 함께 접근**하므로 빠른 IPC 방식이다.

하지만 여러 프로세스가 동시에 값을 수정하면:

```text
Race Condition
```

이 발생할 수 있다.

따라서 실제 사용에서는 보통:

```text
Shared Memory
+
Semaphore / Mutex
```

처럼 **데이터 공유 + 동기화**를 함께 사용한다.

예:

```text
Semaphore 획득
     ↓
Shared Memory 접근
     ↓
Semaphore 반환
```

즉 이전에 배운 System V Semaphore와 공유 메모리는 실제로 함께 사용되는 경우가 많다.

## 메세지 큐

메세지 큐를 사용하면 프로세스들 끼리 자료를 손쉽게 교환할 수 있다

\[유저 영역\] 프로세스 ← \[커널 영역\] 메세지 큐

<a id="notion-3e41d46c18fc80518318f650b8fdb865"></a>

### 메세지 큐 생성

msgget // 기능, 리턴, 매개변수

<a id="notion-3e41d46c18fc80c09952e29709126f88"></a>

### 메세지 큐 제어

msgctl // 기능, 리턴, 매개변수

<a id="notion-3e41d46c18fc802d8c86d7300f47838b"></a>

### 메세지 보내기

msgsnd // 기능, 리턴, 매개변수

msgp

```c
struct msg_buf
{
	long mtype;
	char mtext[64];
};
```

mtype은 필수이고 나머지는 자유롭게 정의해서 사용 가능

mtype은 반드시 long 타입이어야 하고 0보다 커야 함

msgsz

msgp가 가리키는 구조체에서 mtype의 크기(long 타입의 크기)를 제외한 크기 // 중요

msgflg

msgsnd()는 큐에 충분한 공간이 있다면 즉시 메세지를 큐에 보냄. 그러나 큐에 충분한 공간이 없다면 공간이 생길 때까지 잠듦. 단, msgflg를 IPC\_NOWAIT로 하면 잠들지 않고 즉시 에러를 리턴함 // 중요

<a id="notion-3e41d46c18fc80feaed3d8c20f980cfa"></a>

### 메세지 받기

msgrcv // 기능, 리턴, 매개변수

// 시험 잘나옴 msgrcv

msgp

msgsnd()에 사용되는 타입과 동일한 구조체 타입을 가리킴

msgsz

msgp가 가리키는 구조체에서 mtype의 크기(long 타입의 크기)를 제외한 크기

msgtyp // 중요(별4개)

0, 0초과, 0 미만 // 시험 문제 mtype 0이 없는데 함정 조심 헷갈리게 나옴

msgflg // 중요

msgrcv()는 큐에 원하는 메세지가 있따면 즉시 메세지를 큐에서 읽음. 그러나 큐에 원하는 메세지가 없다면 원하는 메세지가 생길 때까지 잠듦. 단, msgflg를 IPC\_NOWAIT로 하면 잠들지 않고 즉시 에러를 리턴함

<a id="notion-3e41d46c18fc8066adf1d2f5e80b6baf"></a>

### 메세지큐 예제

\[msg.h\]

```c
#define KEY_MSG 0x3330

struct msg_buf
{
	long mtype;
	char mtext[64];
};
```

\[msgctl.c\]

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <errno.h>
#include <string.h>
#include <fcntl.h>
#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/msg.h>

#include "msg.h"

pid_t pid;

int main(int argc, char **argv)
{
	int ret;
	int id_msg;

	if (argc != 2)
	{
		printf("usage: %s {command}\n", argv[0]);
		return EXIT_FAILURE;
	}
	printf("[%d] running %s %s\n", pid = getpid(), argv[0], argv[1]);

	id_msg = msgget((key_t)KEY_MSG, 0666 | IPC_CREAT); // 메세지 큐 생성
	if (id_msg == -1)
	{
		printf("[%d] error: %s (%d)\n", pid, strerror(errno), __LINE__);
		return EXIT_FAILURE;
	}

	if (strcmp(argv[1], "IPC_STAT") == 0)
	{
		struct msqid_ds dsbuf;
		ret = msgctl(id_msg, IPC_STAT, &dsbuf); // 메세지 큐 정보 획득
		if (ret == -1)
		{
			printf("[%d] error: %s (%d)\n", pid, strerror(errno), __LINE__);
			return EXIT_FAILURE;
		}
		printf("[%d] IPC_STAT OK\n", pid);
		printf("    msg_perm.__key=%#x\n", dsbuf.msg_perm.__key);
		printf("    msg_perm.mode=%#o\n", dsbuf.msg_perm.mode);
		printf("    msg_qbytes=%ld\n", dsbuf.msg_qbytes);
	}
	else if (strcmp(argv[1], "IPC_RMID") == 0)
	{
		ret = msgctl(id_msg, IPC_RMID, 0); // 메세지 큐 제거
		if (ret == -1)
		{
			printf("[%d] error: %s (%d)\n", pid, strerror(errno), __LINE__);
			return EXIT_FAILURE;
		}
		printf("[%d] IPC_RMID OK\n", pid);
	}

	printf("[%d] terminted\n", pid);

	return EXIT_SUCCESS;
}
```

\[msgsnd.c\]

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <errno.h>
#include <string.h>
#include <fcntl.h>
#include <time.h>
#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/msg.h>

#include "msg.h"

pid_t pid;
struct msg_buf msgarr[] = {{1, "text1"}, {2, "text2"}, {3, "text3"}, {4, "text4"}, {5, "text5"}, {4, "text4"}, {5, "text5"}, {6, "text6"}, {7, "text7"}, {8, "text8"}};

int main(int argc, char **argv)
{
	int ret;
	int id_msg;
	int i;

	if (argc != 1)
	{
		printf("usage: %s\n", argv[0]);
		return EXIT_FAILURE;
	}
	printf("[%d] running %s\n", pid = getpid(), argv[0]);

	id_msg = msgget((key_t)KEY_MSG, 0666 | IPC_CREAT); // 메세지 큐 할당
	if (id_msg == -1)
	{
		printf("[%d] error: %s (%d)\n", pid, strerror(errno), __LINE__);
		return EXIT_FAILURE;
	}

	for (i = 0; i < sizeof(msgarr) / sizeof(msgarr[0]); i++)
	{
		ret = msgsnd(id_msg, (void *)&msgarr[i], sizeof(struct msg_buf) - sizeof(long), 0); // 메세지 보내기
		if (ret == -1)
		{
			printf("[%d] error: %s (%d)\n", pid, strerror(errno), __LINE__);
			return EXIT_FAILURE;
		}
	}

	printf("[%d] terminted\n", pid);

	return EXIT_SUCCESS;
}
```

\[msgrcv.c\]

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <errno.h>
#include <string.h>
#include <fcntl.h>
#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/msg.h>

#include "msg.h"

pid_t pid;

int main(int argc, char **argv)
{
	int ret;
	int id_msg;
	struct msg_buf msgbuf;
	long mtype = atoi(argv[1]);

	if (argc != 2)
	{
		printf("usage: %s {mtype}\n", argv[0]);
		return EXIT_FAILURE;
	}
	printf("[%d] running %s %s\n", pid = getpid(), argv[0], argv[1]);

	id_msg = msgget((key_t)KEY_MSG, 0666 | IPC_CREAT); // 메세지 큐 할당
	if (id_msg == -1)
	{
		printf("[%d] error: %s (%d)\n", pid, strerror(errno), __LINE__);
		return EXIT_FAILURE;
	}

	ret = msgrcv(id_msg, (void *)&msgbuf, sizeof(struct msg_buf) - sizeof(long), mtype, IPC_NOWAIT); // 메세지 받기
	if (ret == -1)
	{
		printf("[%d] error: %s (%d)\n", pid, strerror(errno), __LINE__);
		return EXIT_FAILURE;
	}
	printf("[%d] mtype=%ld, mtext=%s\n", pid, msgbuf.mtype, msgbuf.mtext);

	printf("[%d] terminted\n", pid);

	return EXIT_SUCCESS;
}
```
