## 📌 SysTick (System Tick) 타이머 요약 정리

<a id="notion-3a41d46c18fc804a98a3cd155303d044"></a>

### 1\. SysTick이란?

- **Cortex-M 코어 내장 타이머:** STM32 주변장치(PERIPHERAL) 타이머와 달리 ARM Cortex-M CPU 코어 내부에 기본 탑재된 24비트 다운-카운터(Down-counter).
- **주요 용도:**

  - OS(FreeRTOS 등)의 틱(Tick) 심장박동 역할.
  - `Delay()` 함수 구현 (정밀한 ms/us 단위 딜레이).
  - 시스템 업타임(Uptime) 측정.

<a id="notion-3a41d46c18fc8053a664e2ac3b4f239e"></a>

### 2\. 핵심 동작 방식 &amp; 특징

- **24비트 감산(Down) 카운터:** `LOAD` 값에서 시작하여 `0`을 향해 카운트다운.
- **자동 재적재 (Auto-reload):** `0`에 도달하면 `LOAD` 레지스터의 값이 `VAL` 레지스터로 자동 복사되어 다시 카운트다운 시작.
- **`N + 1`** <strong>법칙:</strong> `0`까지 세고 리셋되므로, $N$번 카운트하려면 `LOAD` 값에 $N - 1$을 설정해야 함.

<a id="notion-3a41d46c18fc80fda2eef9521b1d37cd"></a>

### 3\. 주요 4대 레지스터 (Register)

|  |  |  |
| --- | --- | --- |
| **레지스터** | **비트** | **설명** |
| **`CTRL`** (Control &amp; Status) | 32비트 | SysTick 동작 설정 및 상태 확인 (Enable, Clock Source, Interrupt, CountFlag) |
| **`LOAD`** (Reload Value) | 24비트 | 카운트 시작 초기값 (최대 `0x00FFFFFF` = 16,777,215) |
| **`VAL`** (Current Value) | 24비트 | 현재 카운트되고 있는 값 (Write 시 `0`으로 초기화 및 CountFlag Clear) |
| **`CALIB`** (Calibration) | 32비트 | 10ms 단위 틱 보정을 위한 팩토리 하드웨어 값 |

<a id="notion-3a41d46c18fc8034ba0bcda243543936"></a>

#### 💡 `CTRL` 레지스터 핵심 비트

- **`Bit 0`** <strong>(ENABLE):</strong> `1` = 타이머 동작 시작 / `0` = 정지
- **`Bit 1`** <strong>(TICKINT):</strong> `1` = 0 도달 시 SysTick 예외(인터럽트) 발생 / `0` = 발생 안 함
- **`Bit 2`** <strong>(CLKSOURCE):</strong> `1` = CPU 클럭(HCLK) 사용 / `0` = 외부 클럭(HCLK / 8) 사용
- **`Bit 16`** <strong>(COUNTFLAG):</strong> 카운트가 `0`에 도달하면 `1`로 세팅됨 (레지스터를 Read하면 자동 `0`으로 Clear)

<a id="notion-3a41d46c18fc80879d15ebe1bb64ff80"></a>

### 4\. 시계 산출 공식 (HCLK / 8 기준)

$\text{Reload Value (LOAD)} = \left( \frac{\text{HCLK}}{8} \div 1000 \right) \times \text{목표시간(ms)} - 1$

- 예: HCLK = $168\text{MHz}$인 경우

  - $\text{HCLK} / 8 = 21\text{MHz}$ ($1\text{초에 } 21,000,000\text{ 카운트}$)
  - $1\text{ms}$ 만들기 $\rightarrow 21,000 - 1 = 20,999$ (`LOAD` 세팅값)

<a id="notion-3a41d46c18fc80c7b9bee51a6fc5b7c4"></a>

### 💬 한 줄 요약

> **"SysTick은 ARM 코어 내부의 24비트 다운-카운터로, LOAD에서 0까지 세고 다시 자동으로 찰지게 되감아주는 정밀한 시계이다\!"**

```c
#include "device_driver.h"

void SysTick_Run(unsigned int msec)
{
	// Timer 설정 : 인터럽트 발생 안함, clock source는 HCLK/8, Timer 정지
	Macro_Write_Block(SysTick->CTRL, 0x7, 0x0, 0U);

	// 주어진 msec 값 만큼의 msec를 count하는 초기값 설정 (LOAD)
	SysTick->LOAD = (int)((HCLK / 8. / 1000.) + 0.5) * msec - 1;

	// VAL 레지스터 값 초기화(0) 및 COUNTFLAG Clear
	SysTick->VAL = 0;

	// Timer Start (시작이 되면 자동으로 LOAD의 값을 VAL로 가져간다)
	Macro_Set_Bit(SysTick->CTRL, 0U);
}

int SysTick_Check_Timeout(void)
{
	// Timer의 Timeout이 발생하면 참(1)리턴, 아니면 거짓(0) 리턴
	return Macro_Check_Bit_Set(SysTick->CTRL, 16U);
}

unsigned int SysTick_Get_Time(void)
{
	// Timer의 현재 count 값 리턴
	return SysTick->VAL;
}

unsigned int SysTick_Get_Load_Time(void)
{
	// Timer에 설정된 초기값을 리턴
	return SysTick->LOAD;
}

void SysTick_Stop(void)
{
	// Timer Stop
	Macro_Clear_Bit(SysTick->CTRL, 0U);
}
```

## 📌 STM32 TIMx (General-Purpose Timer) 요약 정리

<a id="notion-3a41d46c18fc808f8971d41ebc8cf9d9"></a>

### 1\. TIMx 타이머란?

- **STM32 주변장치(Peripheral) 타이머:** ARM 코어 외부에 독립적으로 존재하는 범용 타이머.
- **주요 용도:**

  - 주기적인 인터럽트 발생 (정확한 시간 간격 주기 제어)
  - PWM(Pulse Width Modulation) 신호 생성 (모터 속도 제어, LED 밝기 제어)
  - 외부 입력 펄스 계측 (Input Capture: 주파수/신호 폭 측정)
  - 엔코더(Encoder) 신호 처리

<a id="notion-3a41d46c18fc80308e5fcf2ffa68baf0"></a>

### 2\. Time-Base Unit 3대 핵심 레지스터

|  |  |  |  |
| --- | --- | --- | --- |
| **레지스터** | **비트** | **이름** | **역할** |
| **`TIMx->CNT`** | 16/32비트 | **Counter** | 실시간으로 숫자를 세고 있는 '현재 시계 바늘' |
| **`TIMx->PSC`** | 16비트 | **Prescaler** | 원본 클럭을 쪼개어 타이머 카운트 속도를 조절하는 '분주기' |
| **`TIMx->ARR`** | 16/32비트 | **Auto-Reload Register** | 카운트의 목표 지점 / 리셋 기준선 (초기 적재 값) |

<a id="notion-3a41d46c18fc80dfb1bbcb8a34d2c811"></a>

### 3\. 카운트 동작 방식 3가지

<a id="notion-3a41d46c18fc8068b68dd86af79ebf4e"></a>

#### 1\) UP Counting (상향 카운트 - 가장 흔함)

- $0 \longrightarrow \text{ARR}$ 방향으로 증가
- `CNT`가 `ARR` 값에 도달하면 `0`으로 리셋되며 **오버플로우(Overflow) / UEV(Update Event)** 발생

<a id="notion-3a41d46c18fc80259bcfe50421f2406e"></a>

#### 2\) DOWN Counting (하향 카운트)

- $\text{ARR} \longrightarrow 0$ 방향으로 감소
- `CNT`가 `0`에 도달하면 `ARR` 값으로 리셋되며 **언더플로우(Underflow) / UEV(Update Event)** 발생

<a id="notion-3a41d46c18fc80eb812ffdf90a85bf30"></a>

#### 3\) Center-Aligned Counting (중앙 정렬 카운트)

- $0 \longrightarrow \text{ARR} \longrightarrow 0$ (UP과 DOWN을 반복)
- 정밀한 PWM 주파수 제어 및 모터 드라이브 제어에 사용

<a id="notion-3a41d46c18fc80a09d60f3c0e3087bd0"></a>

### 4\. 타이머 주기(시간) 계산 공식

타이머의 최종 주기 $T$ (초 단위) 및 주파수 $f$ 계산식:

$T = \frac{(\text{PSC} + 1) \times (\text{ARR} + 1)}{f_{\text{TIM\_CLK}}}$

- <strong>$f_{\text{TIM\_CLK}}$</strong><strong>:</strong> 타이머로 들어오는 공급 클럭 주파수 (예: 84MHz)
- <strong>`+1`</strong>**을 하는 이유:** 레지스터 설정값 `0`이 실제로는 '1번의 클럭 펄스'를 의미하기 때문 ($N$을 세려면 레지스터에 $N-1$ 저장)

<a id="notion-3a41d46c18fc80a78b89d68f01834072"></a>

#### 💡 예시 (84MHz 클럭에서 1초(1Hz) 만들기)

1. **`PSC`** <strong>= 8399</strong> 세팅 $\rightarrow 84\,\text{MHz} \div (8399 + 1) = 10\,\text{kHz}$ ($0.1\,\text{ms}$ 마다 1카운트)
2. **`ARR`** <strong>= 9999</strong> 세팅 $\rightarrow 10\,\text{kHz} \div (9999 + 1) = 1\,\text{Hz}$ ($1\,\text{초}$ 완료)

<a id="notion-3a41d46c18fc801099cee37517dca8be"></a>

### 5\. 주요 이벤트 및 플래그 (Flag)

- **UEV (Update Event):** 카운터가 `ARR` 도달(UP) 또는 `0` 도달(DOWN) 시 발생하는 하드웨어 이벤트.
- **UIF (Update Interrupt Flag):** `TIMx->SR` (Status Register)의 Bit 0. UEV가 발생하면 `1`로 세팅되며, 소프트웨어에서 처리 후 `0`으로 직접 Clear 해주어야 함.

<a id="notion-3a41d46c18fc80b1a4cad8023614195b"></a>

### 💬 한 줄 요약

> **"TIMx는 Prescaler(PSC)로 속도를 줄이고, Auto-Reload(ARR)로 한계선을 정해 Counter(CNT)가 펄스를 세며 정확한 주기와 PWM을 만들어내는 범용 시계이다\!"**

<a id="notion-3a41d46c18fc8098bdede4785718b18f"></a>

### 6\. 주요 제어/이벤트 레지스터 (추가)

|  |  |  |  |
| --- | --- | --- | --- |
| **레지스터** | **비트** | **이름** | **역할** |
| **`TIMx->CR1`** | 16비트 | **Control Register 1** | 타이머의 동작 방식을 총괄 설정하는 **메인 컨트롤러** (ON/OFF, 카운트 방향, 정지 조건 등) |
| **`TIMx->EGR`** | 16비트 | **Event Generation Register** | 소프트웨어로 강제로 이벤트를 찔러 넣어주는 **이벤트 발생기** |

<a id="notion-3a41d46c18fc80f88712f8f82ced8be0"></a>

### 🔍 `TIMx->CR1` (Control Register 1) 주요 비트

타이머 동작 시 가장 자주 건드리는 핵심 비트들입니다.

- **`Bit 0`** <strong>(CEN - Counter Enable):</strong> **타이머 ON/OFF 스위치**

  - `1`: 카운터(`CNT`) 동작 시작
  - `0`: 카운터 동작 정지
- **`Bit 4`** <strong>(DIR - Direction):</strong> **카운트 방향 설정**

  - `0`: Up-counter (0 $\rightarrow$ ARR)
  - `1`: Down-counter (ARR $\rightarrow$ 0)
- **`Bit 3`** <strong>(OPM - One-pulse Mode):</strong> **단발성 동작 설정**

  - `0`: 무한 반복 카운트
  - `1`: 한 주기(오버플로우)만 돌고 알아서 `CEN = 0`이 되며 자동 정지
- **`Bit 7`** <strong>(ARPE - Auto-reload Preload Enable):</strong> **ARR 버퍼링 설정**

  - `1`: `ARR` 값을 수정해도 바로 반영되지 않고, 현재 주기가 끝나는(Update Event) 시점에 안전하게 반영됨 (PWM 제어 시 필수)
  - `0`: `ARR` 값을 바꾼 즉시 적용됨

<a id="notion-3a41d46c18fc805fbf6ad9cabaa63f63"></a>

### 🔍 `TIMx->EGR` (Event Generation Register) 주요 비트

소프트웨어적으로 타이머의 상태를 즉시 리셋하거나 강제로 업데이트할 때 사용합니다. (Write-Only 레지스터)

- **`Bit 0`** <strong>(UG - Update Generation):</strong> **강제 업데이트 이벤트 발생**

  - `1`을 쓰는 순간 타이머 내부가 리셋됩니다:

    1. 카운터(`CNT`)가 즉시 `0`(또는 ARR)으로 리셋됨
    2. 설정한 `PSC`와 `ARR` 값이 타이머의 실제 동작 섀도우 레지스터(Shadow Register)로 즉시 적용됨
    3. 프레스케일러(PSC) 카운터도 `0`으로 리셋됨
  - <em>팁: 타이머 초기화 코드 마지막에</em> <em>`TIMx->EGR |= (1 << 0);`</em>*을 한번 실행해 주면 변경된 PSC/ARR 값이 즉시 확실하게 적용됩니다.*

<a id="notion-3a41d46c18fc8010b6c4c827786fc9fe"></a>

### 💡 Hz(헤르츠) 직관적 이해하기

- **$1\text{Hz}$** = 1초에 펄스가 **1번** 뜀 ($1\text{초}$에 카운트 1개)
- **$10\text{Hz}$** = 1초에 펄스가 **10번** 뜀 ($0.1\text{초}$마다 카운트 1개)
- **$1\,\text{kHz} (1,000\text{Hz})$** = 1초에 펄스가 **1,000번** 뜀 ($1\text{ms}$마다 카운트 1개)
- **$50\,\text{kHz} (50,000\text{Hz})$** = 1초에 펄스가 **50,000번** 뜀 ($20,\mu\text{s}$마다 카운트 1개) 👈 *방금 구현하신 설정\!*

<a id="notion-3a41d46c18fc80d0a4b8cdf0936dfb4f"></a>

### 🔄 주파수(Hz)와 시간(주기, $T$)의 관계

주파수($f$)와 펄스 1개가 뛰는 데 걸리는 시간인 주기($T$)는 서로 **역수 관계**입니다.

$f = \frac{1}{T} \quad \Longleftrightarrow \quad T = \frac{1}{f}$

아까 작성하셨던 매크로 수식을 이 공식에 적용해 보면:

1. <strong>"펄스 1개 시간(</strong><strong>$20\,\mu\text{s}$</strong><strong>)으로 주파수(Hz) 구하기"</strong>

   - $20\,\mu\text{s} = 0.00002\text{초}$
   - $\text{주파수}(f) = \frac{1}{0.00002\text{초}} = \mathbf{50,000\,\text{Hz} (50\,\text{kHz})}$
   - ➔ **"1초에 50,000번 뛰는 시계구나\!"**
2. <strong>"주파수(</strong><strong>$50,000\text{Hz}$</strong><strong>)로</strong> **$1\text{ms}$** <strong>동안 뛰는 펄스 수 구하기"</strong>

   - 1초($1,000\text{ms}$)에 50,000번 뛰므로, $1\text{ms}$에는 1,000으로 나눈 <strong>$50$</strong>**번**이 뜀.
   - ➔ **"1ms 딜레이를 주려면 타이머로 50번을 세면 되겠구나\!”**

```c
void TIM2_Stopwatch_Start(void)
{
	Macro_Set_Bit(RCC->APB1ENR, 0U);

	// TIM2 CR1 설정: down count, one pulse
	TIM2->CR1 = (0x1U << 3U) | (0x1U << 4U);
	// PSC 초기값 설정 => 20usec tick이 되도록 설계 (50KHz)
	// 분주는 N + 1이 설정되므로 -1 해줘야함.
	TIM2->PSC = (unsigned int)(TIMXCLK / TIM2_FREQ + 0.5) - 1U;
	// ARR 초기값 설정 => 최대값 0xFFFF 설정
	TIM2->ARR = TIM2_MAX;
	// UG 이벤트 발생
	Macro_Set_Bit(TIM2->EGR, 0U);
	// TIM2 start
	Macro_Set_Bit(TIM2->CR1, 0U);
}

unsigned int TIM2_Stopwatch_Stop(void)
{
	unsigned int time;

	// TIM2 stop
	Macro_Clear_Bit(TIM2->CR1, 0U);
	// CNT 초기 설정값 (0xffff)와 현재 CNT의 펄스수 차이를 구하고
	// 그 펄스수 하나가 20usec이므로 20을 곱한값을 time에 저장
	time = (TIM2_MAX - TIM2->CNT) * TIM2_TICK;
	// 계산된 time 값을 리턴(단위는 usec)
	return time;
}

void TIM2_Delay(int time)
{
	Macro_Set_Bit(RCC->APB1ENR, 0U);

	TIM2->CR1 = (0x1U << 4U) | (0x1U << 3U);
	TIM2->PSC = (unsigned int)(TIMXCLK / TIM2_FREQ + 0.5) - 1;

	unsigned int pls = TIM2_1ms_Pls * time;
	unsigned int q = pls / TIM2_MAX;
	unsigned int r = pls % TIM2_MAX;
	unsigned int i;

	for (i = 0U; i < q; i++)
	{
		TIM2->ARR = TIM2_MAX - 1U;

		Macro_Set_Bit(TIM2->EGR, 0U);
		Macro_Clear_Bit(TIM2->SR, 0U);
		Macro_Set_Bit(TIM2->CR1, 0U);

		while (!Macro_Check_Bit_Set(TIM2->SR, 0U))
			;
	}

	if (r > 0U)
	{

		TIM2->ARR = r - 1U;

		Macro_Set_Bit(TIM2->EGR, 0U);
		Macro_Clear_Bit(TIM2->SR, 0U);
		Macro_Set_Bit(TIM2->CR1, 0U);

		while (!Macro_Check_Bit_Set(TIM2->SR, 0U))
			;
	}

	// TIM2 Stop
	Macro_Clear_Bit(TIM2->CR1, 0U);
}

void TIM4_Repeat(int time)
{
	Macro_Set_Bit(RCC->APB1ENR, 2U);

	// TIM4 CR1: ARPE=0, down counter, repeat mode
	TIM4->CR1 = (0x1U << 4U) | (0x0U << 3U);
	// PSC(50KHz), ARR(reload 시 값) 설정
	TIM4->PSC = (unsigned int)(TIMXCLK / TIM2_FREQ + 0.5) - 1;
	TIM4->ARR = (unsigned int)(TIM2_1ms_Pls * time);
	// UG 이벤트 발생
	Macro_Set_Bit(TIM4->EGR, 0U);
	// Update Interrupt Pending Clear
	Macro_Clear_Bit(TIM4->SR, 0U);
	// TIM4 start
	Macro_Set_Bit(TIM4->CR1, 0U);
}

int TIM4_Check_Timeout(void)
{
	// 타이머가 timeout 이면 1 리턴, 아니면 0 리턴
	int is_timeout = Macro_Check_Bit_Set(TIM4->SR, 0U);
	if (is_timeout)
	{
		Macro_Clear_Bit(TIM4->SR, 0U);
	}
	return is_timeout;
}

void TIM4_Stop(void)
{
	Macro_Clear_Bit(TIM4->CR1, 0U);
}

void TIM4_Change_Value(int time)
{
	TIM4->ARR = 50 * time;
}
```
