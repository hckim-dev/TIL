## 1\. 포인터의 본질: "망원경"

- **포인터는 특정 메모리 주소를 바라보는 망원경**입니다.
- `int *p`나 `char *p`처럼 **포인터의 타입**은 그 주소에서 "몇 바이트 크기로 읽을 것인가(윈도우 크기)"와 "어떻게 해석할 것인가"를 결정합니다.
- <strong>포인터 연산 (</strong><strong>`p + 1`</strong><strong>)</strong>: 단순히 주솟값에 1이 더해지는 게 아니라, <strong>`가리키는 타입의 크기`</strong>**만큼 주소가 이동**합니다. (예: `int*`에서 `+1`은 주소가 4바이트 증가)

<a id="notion-3ad1d46c18fc8031a973eb67b832303f"></a>

## 2\. 배열과 포인터의 2가지 핵심 공식

<a id="notion-3ad1d46c18fc8058824dcd880b46b82b"></a>

### ① 배열 정의 공식

- **`a == &a[0]`** : 배열 이름은 배열의 첫 번째 요소의 주소입니다.
- **배열의 양면성**: 배열 이름 `a`는 기본적으로 포인터처럼 동작하지만, `sizeof(a)`와 `&a`를 만날 때만 '배열 전체'로 해석됩니다.

<a id="notion-3ad1d46c18fc8001a8d2f8ad2975a780"></a>

### ② 배열 활용 공식 (컴파일러의 비밀)

- **`a[i] == *(a + i)`**
- C 컴파일러 내부에는 사실 `[]` 연산자가 없습니다. 우리가 `a[i]`라고 쓰면 컴파일러가 알아서 `(a + i)`라는 포인터 연산으로 바꿔서 처리합니다.

<a id="notion-3ad1d46c18fc806e98fadf89c63f184d"></a>

## 3\. 선언할 때 vs 쓸 때 기호의 의미

- , `[]`, `()` 기호는 선언할 때와 수식에서 쓰일 때의 역할이 전혀 다릅니다.
- **선언할 때 (Modifier)**

  -  : 주소화 (포인터로 만듦)
  - `[]` : 집합화 (배열로 만듦)
  - `()` : 함수화 (함수로 만듦)
- **수식에서 쓰일 때 (Operator)**

  -  : 내용 꺼내기 (역참조)
  - `[]` : 특정 요소 가리키기
  - `()` : 함수 실행하기

> **💡 주소 전용 연산자 4가지**
>
> - , `[]`, `()`, `>` 이 4개 연산자 뒤에는 **반드시 주소 타입**이 와야 합니다.

<a id="notion-3ad1d46c18fc803b902ac11a151cbabc"></a>

## 4\. C언어에서 '주소'를 뜻하는 4가지와 L-value

C언어에서 `&`를 붙이지 않아도 그 자체로 주소인 것은 딱 4가지입니다.

1. **배열명** (`a`)
2. **함수명** (`main`, `add`)
3. **문자열 상수** (`"Hello"`)
4. **포인터 변수** (`p`)

**중요한 점:** 이 중에서 주솟값을 내 마음대로 바꿀 수 있는 것(L-value, 좌변에 올 수 있는 것)은 오직 <strong>4번 포인터 변수(</strong><strong>`p`</strong><strong>)</strong> 뿐입니다. 나머지는 주소를 바꿀 수 없는 상수 취급입니다.

<a id="notion-3ad1d46c18fc80f7972ec3da48961a3e"></a>

## 5\. 실전 고급 포인터 팁

<a id="notion-3ad1d46c18fc8002a5bee9a6e5c9142f"></a>

### ① 포인터 강제 형변환(Casting) 공식

주소를 포인터 변수 `p`에 강제로 대입할 때는, **변수 이름만 쏙 빼고** 괄호 쳐서 캐스팅하면 됩니다.

- `int *p;` $\rightarrow$ `p = (int *)0x1000;`
- `int (*p)[4];` $\rightarrow$ `p = (int (*)[4])0x1000;`

<a id="notion-3ad1d46c18fc8045b076f63f0f1b5c89"></a>

### ② 배열 등가 포인터 만들기

함수 매개변수로 배열을 넘길 때는 배열 크기 대신 등가 포인터를 씁니다.

- **방법:** 가장 바깥쪽 배열 차원만 `(*p)`로 바꿔주면 끝납니다.

  - `int a[4]` $\rightarrow$ `int *p`
  - `int a[3][4]` $\rightarrow$ `int (*p)[4]`

<a id="notion-3ad1d46c18fc80898a52d147ec8bb508"></a>

### ③ 함수 포인터

- **`add == &add`** : 함수 이름 자체가 함수의 시작 주소입니다.
- `int (*p)(int, int);` 로 선언 후 `p = add;` 대입하면 `p(3, 4);` 처럼 함수를 변수처럼 호출할 수 있습니다.
