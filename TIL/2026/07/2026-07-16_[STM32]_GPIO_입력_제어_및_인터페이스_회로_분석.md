### 📌 1. 디지털 로직의 3가지 상태

- **`0`** <strong>(Low):</strong> 그라운드(GND)와 연결된 확실한 0V 상태
- **`1`** <strong>(High):</strong> 전원(Vcc)과 연결된 확실한 공급 전압 상태
- **플로팅 (Floating / Hi-Z):** 0V도, Vcc도 아닌 공중에 붕 뜬 애매한 상태 (전기적 노이즈에 의해 0과 1을 제멋대로 오감)

  - **전기적 관점:** 플로팅 (Floating)
  - **회로/설계 관점:** 하이 임피던스 (High Impedance / Hi-Z)
  - **디지털 로직 관점:** 3-State (삼태 상태)

<a id="notion-39f1d46c18fc8024be10f613721591ed"></a>

### 📌 2. 풀업/풀다운이 없을 때의 스위치 오동작 분석

|  |  |  |  |
| --- | --- | --- | --- |
| **스위치 연결 상태** | **누름 (Pressed)** | **뗌 (Released)** | **발생 문제 및 원인** |
| **전원(Vcc)에 연결** | **`1`** <strong>(확실)</strong> | **알 수 없음 (플로팅)** | 스위치를 떼면 핀이 공중에 뜨므로 0인지 1인지 모름 |
| **GND에 연결** | **`0`** <strong>(확실)</strong> | **알 수 없음 (플로팅)** | 스위치를 떼면 핀이 공중에 뜨므로 0인지 1인지 모름 |

<a id="notion-39f1d46c18fc803a9e72f1c4f0c201b8"></a>

### 📌 3. "달고 떼면 0, 누르면 쇼트(Short)?" 원리 이해

<a id="notion-39f1d46c18fc800482e1c31817e06476"></a>

#### ❌ 잘못 구현된 예시 (저항 없이 전원과 그라운드를 다이렉트로 연결 시)

> **"누르면 숏(합선)?"** ➡️ **네, 저항이 없으면 칩이 타버립니다.**
>
> 스위치가 열렸을 때 `0`을 주려고 핀을 GND에 묶고, 스위치를 눌렀을 때 `1`을 주려고 전원에 묶으면, 스위치를 누르는 순간 **전원(Vcc)과 그라운드(GND)가 직통으로 연결되어 쇼트(Short, 과전류)가 나고 칩이 즉시 파괴**됩니다.

<a id="notion-39f1d46c18fc80f395bbc269ce4a023c"></a>

#### 🟢 올바른 해결책: 풀업(Pull-up) / 풀다운(Pull-down) 저항

이 쇼트 문제를 방지하면서, 평소(뗐을 때)의 상태를 확실한 `1` 또는 `0`으로 묶어두기(Pull) 위해 **중간에 안전빵 저항(보통 10kΩ)을 하나 끼워두는 것**입니다.

- **풀업 (Pull-up):** 저항을 전원(High) 쪽에 달아둠. 평소에는 `1`, 누르면 `0`
- **풀다운 (Pull-down):** 저항을 그라운드(Low) 쪽에 달아둠. 평소에는 `0`, 누르면 `1`

<a id="notion-39f1d46c18fc8032b96df31a4725d260"></a>

### 📌 풀업/풀다운 저항 용량 선정 기준 (10kΩ을 쓰는 이유)

풀업·풀다운 저항은 무조건 아무거나 다는 것이 아니라, 전력 소모(전류량)와 **신호 반응 속도(신호 무결성)** 사이의 적절한 타협점을 찾아 선정합니다. 일반적으로 `10kΩ`이 표준으로 쓰이는 물리적 이유는 다음과 같습니다.

<a id="notion-39f1d46c18fc80708c57fcf9a0677a34"></a>

### 1\. 너무 작은 저항을 쓸 때의 문제 (약 1kΩ 이하: 강한 풀업)

- **문제점:** 스위치를 누르는 순간 흐르는 전류($I = V/R$)가 너무 커져 **전력 소모가 극심**해집니다.
- **예시 (3.3V 전원 기준):**

  - $R = 330\Omega$ 일 때: $I = 3.3V / 330\Omega = 10\text{mA}$ (스위치 하나 누를 때마다 MCU가 감당하기 힘든 큰 전류가 낭비됨)

<a id="notion-39f1d46c18fc80e0abe4c54d04894e84"></a>

### 2\. 너무 큰 저항을 쓸 때의 문제 (약 100kΩ 이상: 약한 풀업)

- **문제점:** 흐르는 전류가 너무 미세해져서 외부 전자기적 노이즈에 쉽게 휘둘립니다. 또한 핀 내부의 기생 커패시턴스(축전 성분) 충전 속도가 느려져 <strong>신호가 0에서 1로 변하는 속도가 매우 느려집니다(시정수</strong> **$\tau = R \times C$** <strong>증가).</strong>
- **예시:** 고속 통신 핀에 100kΩ을 달면 파형이 뭉개져 통신 에러가 발생합니다.

<a id="notion-39f1d46c18fc80edbe67f1ba28f8eb89"></a>

### 3\. 최종 선정 가이드라인

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **저항 크기** | **구분** | **장점** | **단점** | **추천 용도** |
| **`1kΩ ~ 4.7kΩ`** | **Strong (강한 풀업)** | 신호 상승 속도가 매우 빠름, 노이즈에 극도로 강함 | 스위치 입력 시 전력 소모가 비교적 큼 | 고속 통신 라인 (I2C 등) |
| **`10kΩ`** | **표준 (Standard)** | **전력 소모와 신호 속도의 완벽한 밸런스** | 없음 (가장 무난함) | **일반 스위치 / GPIO 입력 (Default)** |
| **`47kΩ ~ 100kΩ`** | **Weak (약한 풀업)** | 스위치 입력 시 전력 소모가 거의 없음 | 신호 반응 속도가 느림, 노이즈에 취약함 | 초절전 저전력 배터리 기기 |

<a id="notion-39f1d46c18fc80429363ce14f4bce40b"></a>

### 🛡️ 칩을 지키는 든든한 방패: **보호 다이오드 (Protection Diode)**

보호 다이오드는 외부에서 들어오는 **비정상적인 고전압(과전압, 정전기 등)으로부터 MCU 내부 회로가 타버리지 않도록 가로막아 보호하는 안전장치**입니다.

보통 MCU의 GPIO 핀 바로 안쪽에 기본적으로 내장되어 있습니다.

<a id="notion-39f1d46c18fc8045899aeee0f91c5434"></a>

### 1\. 왜 필요할까요? (동작 원리)

- **문제 상황:** 손으로 칩을 만질 때 발생하는 정전기(ESD)나 회로 오작동으로 인해 3.3V 전원보다 훨씬 높은 고전압(예: 12V)이 GPIO 핀으로 훅 들어올 수 있습니다.
- **보호가 없다면:** 이 고전압이 내부 핵심 회로(CPU 코어 등)로 직접 흘러 들어가 칩이 그 즉시 영구적으로 사망합니다.
- **해결책:** 핀 입구에 위·아래로 다이오드 2개(상단, 하단)를 배치하여, 비정상적인 전압이 들어오면 핵심 회로로 가지 못하게 각각 전원($V_{DD}$)이나 그라운드($GND$) 쪽으로 흘려보내(Bypass) 버립니다.

<a id="notion-39f1d46c18fc8082ab87c3a180f89a83"></a>

### 2\. 다이오드 2형제의 방어 메커니즘

GPIO 핀 내부에 걸려 있는 2개의 다이오드는 평소에는 문을 닫고 있다가, 위험한 전압이 들어올 때만 작동합니다.

<a id="notion-39f1d46c18fc800598e5c8399d19725f"></a>

#### 윗동네 방패 (상단 다이오드) ➡️ 과전압 차단

- **정상 동작 (0V \~ 3.3V):** 다이오드가 작동하지 않아 신호가 내부 회로로 정상 진입합니다.
- **위험 상황 (3.3V 초과 고전압 유입):** 핀에 5V나 12V 같은 고전압이 들어오면 상단 다이오드가 켜집니다. 들어온 전압이 <strong>전원(</strong><strong>$V_{DD}$</strong><strong>, 3.3V) 쪽으로 빠져나가게 물길을 돌려</strong> 내부 회로를 보호합니다.

<a id="notion-39f1d46c18fc804db728f9cc1be9b2a5"></a>

#### 아랫동네 방패 (하단 다이오드) ➡️ 역전압(마이너스) 차단

- **정상 동작 (0V \~ 3.3V):** 다이오드가 작동하지 않습니다.
- **위험 상황 (0V 미만 마이너스 전압 유입):** 핀에 $-5\text{V}$ 같은 역전압이 들어오면 하단 다이오드가 켜집니다. 이 전류를 <strong>그라운드(</strong><strong>$GND$</strong><strong>, 0V) 쪽으로 안전하게 흡수</strong>시켜 내부 회로를 보호합니다.

<a id="notion-39f1d46c18fc80f4bce5d72a54dc728b"></a>

### ✍️ 노션 요약용 3초 정리

> • **역할:** 정전기나 외부 고전압(과전압)으로부터 MCU 내부 회로를 보호하는 물리적 방패.<br>• **상단 다이오드:** 전원($V_{DD}$)보다 높은 전압이 들어오면 전원선으로 흘려보냄.<br>• **하단 다이오드:** 그라운드($GND$)보다 낮은 음수(-) 전압이 들어오면 그라운드로 흘려보냄.

<a id="notion-39f1d46c18fc808a848ed6f5b9aeff39"></a>

### 💡 내부 풀업/풀다운 저항 (Internal Pull-up / Pull-down)

내부 풀업/풀다운 저항은 말 그대로 외부에 납땜해서 달아야 하는 물리적인 저항을 **MCU 칩 내부(Silicon)에 내장해 둔 것**입니다.

개발자가 코딩(레지스터 설정)을 통해 필요할 때마다 소프트웨어적으로 켜고 끌 수 있게 설계되어 있습니다.

<a id="notion-39f1d46c18fc8039b031d04d703a8fe5"></a>

### 1\. 왜 칩 내부에 달아두었을까요? (존재 이유)

- **비용 및 공간 절약:** 회로 기판(PCB)에 물리적인 저항을 굳이 납땜하지 않아도 되므로, **생산 단가가 절감되고 회로 크기가 획기적으로 줄어듭니다.**
- **설계 유연성 (편의성):** 상황에 따라 이 핀은 풀업으로 쓰고, 저 핀은 풀다운으로 쓸지를 **소프트웨어 코딩 한 줄로 언제든지 바꿀 수 있습니다.**
- **회로 단순화:** 납땜할 소자가 줄어들어 회로가 엄청나게 깔끔해집니다.

<a id="notion-39f1d46c18fc8072b2bcd37fb714c1d7"></a>

### 2\. 내부 저항은 어떻게 작동하나요?

STM32 같은 MCU 내부를 들여다보면, GPIO 핀 하나마다 내부 풀업 저항(보통 약 $30\text{k}\Omega \sim 50\text{k}\Omega$)과 풀다운 저항이 스위치와 함께 매달려 있습니다.

- **풀업 활성화 코드를 작성하면:** 내부 풀업 스위치가 찰칵 닫히면서 핀이 내부 전원($V_{DD}$)과 연결되어 <strong>평상시</strong> **`1`** <strong>상태</strong>가 됩니다.
- **풀다운 활성화 코드를 작성하면:** 내부 풀다운 스위치가 찰칵 닫히면서 핀이 내부 그라운드($GND$)와 연결되어 <strong>평상시</strong> **`0`** <strong>상태</strong>가 됩니다.
- **아무것도 켜지 않으면 (Floating):** 내부 스위치가 둘 다 열려있어 핀이 공중에 뜨는 일반 플로팅 상태가 됩니다.

<a id="notion-39f1d46c18fc80109007ea14cb4cc10b"></a>

### ✍️ 노션 요약용 3초 정리

> • **내부 저항:** 칩 안에 이미 만들어져 있는 풀업/풀다운 저항 ($30\text{k}\Omega \sim 50\text{k}\Omega$ 수준).<br>• **장점:** 외부 저항 납땜 불필요 ➡️ 회로 기판 소형화, 비용 절감, 코드 제어로 유연한 대처 가능.<br>• **용도:** 일반적인 스위치 입력이나 센서 상태 입력을 받을 때 외부 저항 없이 칩 내부 저항을 켜서 초간단하게 구현함.
