## 1. QPixmap (이미지 파일 다루기)

파일 경로에서 직접 불러오거나 Qt 리소스 파일(.qrc)에서 이미지 데이터를 불러와 QLabel 등에 출력할 때 사용합니다.

```c++
#include <QPixmap>

// 1. 일반 파일 경로에서 Load
QPixmap pixmapFile("D:/images/Hydrangeas.jpg");

// 2. Qt 리소스 파일(.qrc)에서 Load
QPixmap pixmapResource(":icon/images/setting.png");

// 3. QLabel에 이미지 적용 (변수 전달 or 직접 전달)
ui->lblPicture->setPixmap(pixmapResource);
// ui->lblPicture->setPixmap(QPixmap(":icon/images/setting.png")); // 한 줄로 표현 가능
```

## 2. QString & QStringList (문자열 다루기)

### 📌 QString::arg() (문자열 포맷팅)

%1, %2, %3 등의 치환자를 두고 뒤이어 .arg()로 순서대로 값을 채워 넣는 방식입니다. (C언어의 sprintf나 Python의 f-string과 유사)

```c++
QString name = "홍길동";
int age = 25;
double height = 175.5;

// %1 -> name, %2 -> age, %3 -> height
QString result = QString("이름: %1, 나이: %2세, 키: %3cm")
                    .arg(name)
                    .arg(age)
                    .arg(height);

// 결과: "이름: 홍길동, 나이: 25세, 키: 175.5cm"
```

### 📌 QStringList (문자열 배열 & 결합)

문자열을 여러 개 담아 다루는 리스트 타입으로, 파이썬의 list 및 join()과 동일하게 동작합니다.

```c++
// 1. 생성 및 데이터 추가
QStringList list;
list.append("Hello");
list.append(" ");
list.append("World");
list.append("!");

// 2. 문자열 합치기 (join)
// 구분자(Separator)를 지정할 수 있으며, ""(빈 문자열)을 넣으면 바로 이어 붙입니다.
QString result = list.join(""); // "Hello World!"
QString joinedWithDash = list.join("-"); // "Hello- -World-!"
```

## 3. 위젯 활용 (QCheckBox & QGroupBox)

### 📌 QCheckBox 핵심 정리

주요 속성 및 메서드

- tristate: 3가지 상태(선택/해제/부분선택) 사용 여부 지정 (true/false)
- isChecked(): 단순 2상태(ON/OFF) 체크 여부 반환 (bool) ➔ 일반 체크박스에 권장
- checkState(): 3가지 세부 상태 값 반환 (Qt::CheckState) ➔ Tristate 체크박스에 권장
주요 시그널 (Signals)

- checkStateChanged(Qt::CheckState): 체크 상태 변경 시 발생 (Qt 6.7+ 권장 ⭐)
- toggled(bool): 체크/해제(ON/OFF) 상태 변경 시 발생
- stateChanged(int): 구버전 시그널 (Qt 6.7부터 Deprecated)
Qt::CheckState 열거형 값 (3가지 상태)

1. Qt::Unchecked (0): 체크 해제
1. Qt::PartiallyChecked (1): 부분 선택 (예: 일부 항목만 체크됨)
1. Qt::Checked (2): 완전 선택
### 📌 QGroupBox

- 연관된 여러 위젯(라디오 버튼, 체크박스 등)을 시각적으로 묶어서 하나의 그룹으로 관리할 때 사용합니다.
## 4. 범용 위젯 전달 & 헬퍼 함수 패턴

특정 위젯(QCheckBox*)이나 최상위 부모 타입(QWidget*) 포인터를 함수 매개변수로 전달하면, 하나의 함수로 여러 위젯의 상태나 스타일을 공통 처리할 수 있습니다.

```c++
// QWidget* 포인터를 받아 범용적으로 배경색을 설정하는 함수
void MainWindow::setBackgroundColor(QWidget* widget, const QString& color){
    // 방어적 코드 (Null Pointer 체크)
    if (!widget) return;

    // QString::arg()를 활용하여 스타일시트 적용
    widget->setStyleSheet(QString("background-color: %1;").arg(color));
}

// 사용 예시
setBackgroundColor(ui->lblState, "red");
setBackgroundColor(ui->chkCpp, "yellow");
```

```c++
// Specific QCheckBox 포인터를 받아 상태를 처리하는 함수
void MainWindow::processStateChanged(QCheckBox* checkbox, int state){
    if (!checkbox) return;
    qDebug() << checkbox->text() << "상태 변경:" << state;
}
```

## 5. C++ / Qt 람다(Lambda) 익명 함수

### 📌 문법 구조

```c++
[ 캡처 리스트 ] ( 파라미터 ) { 실행 로직 };
```

- [] (캡처 리스트): 람다 외부 변수/객체를 내부로 끌어올 때 사용
- () (파라미터): 시그널 등에서 전달받는 인자
- {} (구현부): 실제 수행할 로직 (데이터 가공 및 conditional 처리)
### 📌 주요 [] 캡처 종류

| 캡처 형식 | 설명 |
|---|---|
| [this] | 클래스 멤버 함수/변수에 접근할 때 필수 |
| [x] | 변수 x를 **복사(값)**하여 가져옴 (읽기 전용) |
| [&x] | 변수 x를 **참조(원본 주소)**로 가져옴 (수정 가능) |
| [this, chk] | this 포인터와 특정 변수 chk를 함께 가져옴 |

### 📌 Qt connect + 람다 응용 예시

시그널이 보내주는 인자를 중간에서 필터링하거나 가공하여 처리 함수로 전달할 때 유용합니다.

```c++
// for문을 돌며 여러 체크박스 시그널을 람다 함수로 일괄 연결
const auto checkBoxes = { ui->chkC, ui->chkCpp, ui->chkJava, ui->chkPython };

for (QCheckBox* chk : checkBoxes) {
    // [this, chk]: MainWindow 멤버 함수 접근용(this) + 체크박스 객체 전달용(chk)
    connect(chk, &QCheckBox::stateChanged, this, [this, chk](int state) {
        // 인자로 전달받은 state를 원하는 조건으로 가공하여 함수 호출
        if (state == Qt::Checked) {
            processStateChanged(chk, state);
        }
    });
}
```

## 6. QRadioButton & QButtonGroup

### 📌 QRadioButton (라디오 버튼)

여러 선택지 중 단 하나만 선택(Exclusive)할 수 있는 위젯입니다.

- autoExclusive: 기본값 true. 동일한 부모(QWidget)를 공유하는 라디오 버튼끼리 자동으로 하나의 선택 그룹으로 묶입니다.
- QCheckBox와의 차이점:
```c++
// 개별 라디오 버튼 toggled 시그널 예시
void MainWindow::on_radioFirst_toggled(bool checked){
    if (checked) {
        grade = "First";
    }
}
```

### 📌 QButtonGroup (버튼 그룹)

여러 버튼(RadioButton, CheckBox 등)을 논리적으로 묶어 일괄 관리하는 비시각적(Non-visual) 클래스입니다.

- Qt Designer 설정: 버튼 다중 선택 ➔ 우클릭 ➔ [Assign to button group] ➔ [New button group]
- exclusive 속성: 그룹 내 버튼을 1개만 선택 가능하게 할지 지정 (true/false)
- buttonToggled 시그널 연결:
```c++
// Qt 6 / Qt 5.15+ 권장 시그널 오버로딩 타입 지정
connect(ui->buttonGroup,
        QOverload<QAbstractButton*, bool>::of(&QButtonGroup::buttonToggled),
        this,
        &MainWindow::Use_Lang);
```

> 💡 Tip: buttonToggled는 버튼 변경 시 해제(false)와 선택(true) 이벤트가 2번 발생하므로, 단순 클릭 처리 시에는 buttonClicked 시그널을 사용하는 것이 코드가 더 간결해집니다.

## 7. Container (컨테이너 위젯)

다른 위젯들을 내부에 포함하고 시각적·구조적으로 그룹화하여 관리하는 위젯입니다.

| 컨테이너 종류 | 특징 및 용도 |
|---|---|
| QGroupBox | 여러 위젯을 하나의 사각형 테두리(Frame)와 타이틀로 시각적으로 묶어서 관리 |
| QTabWidget | 상단/하단 탭을 클릭하여 여러 페이지를 전환 (한 번에 1개 페이지만 표시) |
| QToolBox | 아코디언 형태의 서랍식 페이지 전환 위젯 (한 번에 1개 페이지만 표시) |

## 8. Layout Widget & 속성 (레이아웃 배치)

창 크기 변경에 맞춰 위젯들의 위치와 크기를 자동으로 배치·조절해 주는 도구입니다.

### 📌 주요 레이아웃 종류

- Horizontal Layout (QHBoxLayout): 위젯을 가로(수평)로 정렬
- Vertical Layout (QVBoxLayout): 위젯을 세로(수직)로 정렬
- Grid Layout (QGridLayout): 위젯을 바둑판(격자) 형태로 정렬
- Form Layout (QFormLayout): 라벨+입력창 형태의 2열 양식 정렬
- Splitter (QSplitter): 사용자가 경계선을 드래그하여 위젯 크기를 직접 조절
- Layout 해제 / 크기 조정: 등록된 레이아웃을 풀거나 위젯에 맞게 자동으로 상자 크기를 맞춤
### 📌 레이아웃 주요 속성 및 요소

- sizePolicy: 창 크기가 변할 때 위젯이 확대/축소되는 정책 지정 (Fixed, Preferred, Expanding 등)
- Spacer (QSpacerItem): 위젯 사이에 빈 공간을 넣거나 특정 위젯을 한쪽으로 밀어낼 때 사용하는 가상의 공간 위젯
- layoutStretch: 레이아웃 내부 자식 위젯(또는 행/열) 간의 크기 확장 비율 설정
