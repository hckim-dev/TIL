# ⚡ Qt Event Handler (이벤트 처리기) 정리

> 💡 한 줄 요약

## 1. 핵심 개념

- Event Handler란?
- QWidget과의 관계
- 재정의 (Override)
## 2. 주요 Event Handler 목록

| 이벤트 종류 | 가상 함수 (Event Handler) | 인자 (Argument) | 설명 |
|---|---|---|---|
| 키보드 누름 | keyPressEvent() | QKeyEvent* | 키보드 키가 눌렸을 때 호출 |
| 키보드 뗌 | keyReleaseEvent() | QKeyEvent* | 키보드 키에서 손을 뗐을 때 호출 |
| 마우스 클릭 | mousePressEvent() | QMouseEvent* | 마우스 버튼을 눌렀을 때 호출 |
| 마우스 이동 | mouseMoveEvent() | QMouseEvent* | 마우스를 움직일 때 호출 |
| 창 크기 변경 | resizeEvent() | QResizeEvent* | 위젯의 크기가 변경될 때 호출 |

## 3. 예시 코드 (C++ Qt)

### 📄 mainwindow.h (헤더 파일)

```c++
#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>
#include <QKeyEvent>   // 키보드 이벤트 헤더
#include <QMouseEvent> // 마우스 이벤트 헤더

class MainWindow : public QMainWindow {
    Q_OBJECT

public:
    MainWindow(QWidget *parent = nullptr);

protected:
    // 💡 부모(QWidget)의 가상 함수를 override 선언
    void keyPressEvent(QKeyEvent *event) override;
    void mousePressEvent(QMouseEvent *event) override;
};

#endif // MAINWINDOW_H
```

### 📄 mainwindow.cpp (소스 파일)

```c++
#include "mainwindow.h"
#include <QDebug>

MainWindow::MainWindow(QWidget *parent) : QMainWindow(parent) {}

// 1. 키보드 이벤트 재정의
void MainWindow::keyPressEvent(QKeyEvent *event){
    if (event->key() == Qt::Key_Escape) {
        qDebug() << "Esc 키가 눌려 프로그램을 종료합니다.";
        this->close();
    } else {
        // ⚠️ 내가 처리하지 않은 다른 키는 부모의 기본 이벤트 핸들러로 전달
        QMainWindow::keyPressEvent(event);
    }
}

// 2. 마우스 이벤트 재정의
void MainWindow::mousePressEvent(QMouseEvent *event){
    if (event->button() == Qt::LeftButton) {
        // 마우스 좌클릭 시 클릭한 좌표 출력
        qDebug() << "마우스 좌클릭 위치 (X, Y):" << event->pos();
    }
}
```

## 5. Custom Button

```c++
#ifndef MYBUTTON_H
#define MYBUTTON_H

#include <QDebug>
#include <QMouseEvent> // include
#include <QPushButton>

class MyButton : public QPushButton {
    Q_OBJECT

public:
    explicit MyButton(QWidget* parent = nullptr);
    int getClickCount();

protected:
    void mousePressEvent(QMouseEvent* event) override; // override 써주기
    void mouseReleaseEvent(QMouseEvent* event) override;

private:
    int clickCount;
};

#endif // MYBUTTON_H
```

```c++
#include "mybutton.h"

MyButton::MyButton(QWidget* parent)
    : QPushButton(parent)
{
    clickCount = 0;

    setStyleSheet("background-color: yellow;"); // 본인 속성 바꾸는 것이므로 바로 함수 호출
    qDebug() << "MyButton created";
}

int MyButton::getClickCount()
{
    return clickCount;
}

void MyButton::mousePressEvent(QMouseEvent* event)
{
    clickCount++;

    if (event->button() == Qt::LeftButton) {
        setStyleSheet("background-color: red;");
        qDebug() << "mousePressEvent";
    }

    QPushButton::mousePressEvent(event); // 부모 이벤트 호출
}

void MyButton::mouseReleaseEvent(QMouseEvent* event)
{
    if (event->button() == Qt::LeftButton) {
        setStyleSheet("background-color: green;");
        qDebug() << "mouseReleaseEvent";
    }

    QPushButton::mouseReleaseEvent(event);
}

```
