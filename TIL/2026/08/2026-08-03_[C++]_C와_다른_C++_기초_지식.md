# 📌 C++ 기초 핵심 정리

## 1\. C++ 표준 Console 출력 (`<iostream>`)

- **핵심 연산자**: `std::cout`과 <strong>스트림 삽입 연산자(</strong><strong>`<<`</strong><strong>)</strong> 사용.
- **헤더 파일**: C와 달리 `<iostream>`처럼 `.h` 확장자를 붙이지 않음.
- **줄바꿈 처리**:

  - `std::endl`: 줄바꿈 + **버퍼 비우기(flush)** 수행 ➔ 빈번 사용 시 성능 저하.
  - `'\n'`: 단순 줄바꿈 ➔ <strong>권장 (속도 향상)</strong>.

```cpp
#include <iostream>

int main(){
    // std::cout과 << 연산자 사용
    std::cout << "Hello, World!" << '\n';
    return 0;
}
```

## 2\. Namespace와 Scope Resolution Operator (`::`)

- **개념**: 이름 충돌(Name Collision)을 방지하기 위해 상자(범위)를 만드는 기능.
- <strong>Scope Resolution Operator (</strong><strong>`::`</strong><strong>)</strong>: 특정 namespace 내부의 요소에 접근할 때 사용. (C++ 표준 라이브러리는 모두 `std` 영역에 위치)

```cpp
#include <iostream>

namespace CompanyA {
    void print(){ std::cout << "A 회사의 함수\n"; }
}

namespace CompanyB {
    void print(){ std::cout << "B 회사의 함수\n"; }
}

int main(){
    CompanyA::print(); // :: 연산자로 구분
    CompanyB::print();
    return 0;
}
```

## 3\. `using` 키워드를 활용한 Namespace 지정

- <strong>Using Directive (지시어)</strong>: 특정 namespace 전체를 가져옴. (편하지만 이름 충돌 가능성 증가)
- <strong>Using Declaration (선언)</strong>: 특정 개별 요소만 선언하여 가져옴. (**권장**)

```cpp
#include <iostream>

// 1. Using Directive (std 전체 가져오기)
using namespace std;

// 2. Using Declaration (특정 요소만 지정)
using std::cout;
using std::endl;

int main(){
    cout << "std:: 생략 가능" << '\n';
    return 0;
}
```

## 4\. 입출력 조작자 (I/O Manipulators)

- **개념**: 스트림 버퍼의 출력/입력 형식을 변환하는 함수 및 객체 (`<iomanip>` 헤더 사용).
- **상태 유지 유의점**: `hex`, `oct`, `dec`, `setfill` 등 대부분의 조작자는 **한 번 지정하면 변경 전까지 지속**됨. (단, `setw`는 1회성).

```cpp
#include <iostream>
#include <iomanip> // I/O Manipulator 헤더

int main()
{
	int num = 255;

	std::cout << std::showbase << std::uppercase << std::hex << num << '\n'; // 0XFF
	std::cout << num << '\n';						  // 여전히 16진수 유지 (0XFF)
	std::cout << std::dec << num << '\n'; // 10진수로 복구 (255)

	// 너비 지정(1회성) 및 채우기 문자의 지속성
	std::cout << std::setw(7) << std::setfill('0') << std::left << 42 << '\n'; // 4200000
	return 0;
}
```

## 5\. C++ 표준 Console 입력 (`std::cin`)

- **핵심 연산자**: `std::cin`과 <strong>스트림 추출 연산자(</strong><strong>`>>`</strong><strong>)</strong> 사용.
- **입력 버퍼 주의사항**: `cin >>` 사용 후 `getline()`을 쓰면 버퍼에 남은 엔터(`\n`)가 바로 입력되어 넘어가 버림.

  - **해결책**: `cin.ignore()`를 호출해 버퍼의 잔여 문자 제거.

```cpp
#include <iostream>
#include <string>

int main(){
    int age;
    std::string name;

    std::cout << "나이 입력: ";
    std::cin >> age; // 입력 후 엔터('\n')가 버퍼에 남음

    std::cin.ignore(); // 버퍼 비우기 (중요!)

    std::cout << "이름 입력: ";
    std::getline(std::cin, name); // 공백 포함 문자열 입력

    // C 스타일 문자열(char 배열) 처리 시:
    // char str[20];
    // std::cin.getline(str, 20);

    return 0;
}
```

## 6\. 변수 초기화 및 구조체

- **초기화 방식 구분**:

  - `int a = 10;` : Copy Initialization (대입)
  - `int b(20);` : Direct Initialization (직접)
  - `int c{30};` : **Uniform (List) Initialization** (C++11부터 도입된 범용 초기화 방식, 형변환 손실(Narrowing) 방지)
- **C vs C++ 구조체 차이**:

  - C++에서는 구조체 내부 **기본값 초기화 가능**.
  - C++에서는 변수 선언 시 `struct` 키워드 **생략 가능**.

```cpp
#include <iostream>

// C++ 구조체 (기본값 설정 가능, struct 키워드 생략 가능)
struct User {
    int id = 1;       // 기본값 초기화 가능
    std::string name;
};

int main(){
    int b(20);        // Direct 초기화
    int c{30};        // Uniform 초기화 (C++11 권장)
    int arr[2] = {40, 50};

    User u1 = {10, "Kim"}; // struct 키워드 없이 사용
    return 0;
}
```

## 7\. 함수의 Default Parameter (디폴트 매개변수)

- **선언 위치**: **선언부(Header/Prototype)에만 작성**하는 것이 원칙 (구현부 작성 시 컴파일 에러 발생 가능).
- **규칙**: 오른쪽 매개변수부터 **오른쪽에서 왼쪽 순서대로** 채워야 함 (중간만 비워두는 것 불가).
- **매개변수 이름**: 선언부와 구현부의 매개변수 이름이 달라도 컴파일 및 동작 가능.

```cpp
#include <iostream>

// 선언부에만 default parameter 명시
int f2(int x, int y = 10, int z = 20);

int main(){
    std::cout << f2(1) << '\n';       // 1 + 10 + 20 = 31
    std::cout << f2(1, 2) << '\n';    // 1 + 2 + 20 = 23
    std::cout << f2(1, 2, 3) << '\n'; // 1 + 2 + 3 = 6
    return 0;
}

// 구현부에는 default 값을 적지 않음 (매개변수명은 달라도 됨)
int f2(int xx, int yy, int zz){
    return xx + yy + zz;
}
```

## 8\. 함수 Overloading (중복 정의)

- **개념**: 동일한 이름의 함수를 매개변수 구성에 따라 여러 개 정의하는 것.
- **오버로딩 성립 조건**:

  - **매개변수의 개수** 또는 타입(순서 포함)이 달라야 함.
- **오버로딩 불가 조건**:

  - **리턴 타입만 다른 경우**는 오버로딩이 불가능함 (컴파일 에러).

```cpp
#include <iostream>

// 매개변수 개수/타입 차이에 의한 오버로딩
int f(int a){ return a; }
int f(int x, int y){ return x + y; }
void f(double x){ std::cout << "double: " << x << '\n'; }
double f(double x, double y){ return x + y; }

// [불가] 리턴 타입만 다른 경우 ➔ 컴파일 에러 발생!
// double f(int a) { return (double)a; }

int main(){
    f(10);        // f(int) 호출
    f(10, 20);    // f(int, int) 호출
    f(3.14);      // f(double) 호출
    return 0;
}
```

## 9\. Parameter 타입의 Template (템플릿)

- **개념**: 함수/클래스를 작성할 때 타입을 미리 정하지 않고, 컴파일 타임에 전달된 인자에 맞춰 타입을 자동 생성하는 기능.
- <strong>명시적 지정 (</strong><strong>`<Type>`</strong><strong>)</strong>: `f2<int>(...)` 형태처럼 타입을 직접 지정해 주면 자동 형변환 및 모호성 방지에 도움이 됨 (**권장**).
- **`auto`** <strong>반환 타입 (C++14\~)</strong>: 서로 다른 타입(`T1`, `T2`) 간의 연산 결과를 컴파일러가 자동으로 추론.
- <strong>가변 인자 템플릿 &amp; 폴드 표현식 (C++17\~)</strong>: `typename... Args`와 `(... * args)`를 사용해 N개의 인자를 한 번에 연산.

```cpp
#include <iostream>

// 1. 단일 타입 템플릿
template <typename T>
T f1(T x, T y){ return x + y; }

// 2. 입력 타입은 템플릿, 반환 타입 지정
template <typename myT>
myT f2(myT x, int y){ return x + y; }

template <typename myT>
int f3(myT x, int y){ return static_cast<int>(x) + y; }

// 3. 서로 다른 타입 매개변수 & auto 반환 (C++14)
template <typename T1, typename T2>
auto f4(T1 x, T2 y){ return x + y; }

// 4. 가변 인자 템플릿 + Fold Expression (C++17)
template <typename... Args>
auto multiplyAll(Args... args){
    return (... * args);
}

int main(){
    std::cout << f1(10, 20) << '\n';           // T -> int 추론
    std::cout << f1(3.14, 5.5) << '\n';        // T -> double 추론

    // Template Type 명시적 지정 방식 (권장)
    std::cout << f2<int>(10, 20) << '\n';
    std::cout << f2<double>(3.14, 30) << '\n';

    std::cout << f3<int>(10, 20) << '\n';
    std::cout << f3<double>(3.14, 30) << '\n';

    std::cout << f4(3, 5.5) << '\n';           // int + double -> double
    std::cout << multiplyAll(1.5, 2, 4, 0.5) << '\n'; // 6

    return 0;
}
```

## 10\. 동적 메모리 할당 (`new` / `delete`) 및 `inline`

- **`new`** <strong>/</strong> <strong>`delete`</strong>:

  - C의 `malloc`/`free`와 달리, 힙(Heap) 영역 메모리 할당 시 **인스턴스 생성(생성자 호출)** 및 삭제(소멸자 호출)가 함께 이루어짐.
  - 단일 객체는 `delete`, 배열 형태로 할당한 경우 `delete[]`로 해제해야 함.
- **`inline`** <strong>함수</strong>:

  - 함수 호출 오버헤드(스택 생성 및 리턴)를 줄이기 위해, **호출부에 함수 본문 코드를 직접 치환**하는 키워드.
  - **장점**: 실행 속도 향상.
  - **단점**: 오용 시 코드 크기(Code Size)가 증가하여 메모리 낭비 발생. (현대 컴파일러는 키워드 없이도 알아서 최적화 판단함)

```cpp
#include <iostream>

// inline 함수 선언 및 정의
inline int square(int x){ return x * x; }

int main(){
    // 동적 메모리 할당 (인스턴스 생성)
    int* p = new int(10);
    int* arr = new int[5]; // 배열 할당

    std::cout << *p << '\n';
    std::cout << square(5) << '\n'; // 치환되어 실행됨

    // 동적 메모리 해제
    delete p;
    delete[] arr; // 배열 해제 시 [] 필수

    return 0;
}
```

## 11\. C++ 참조자 (Reference) 및 Call by Reference

- <strong>참조자 (</strong><strong>`&`</strong><strong>)</strong>: 기존 변수에 별명(Alias)을 붙이는 개념. 포인터와 달리  연산자 없이 직접 변수처럼 접근 가능.
- **함수 매개변수 전달 방식 비교**:

  - `Call by Value`: 값 복사 발생 (원본 영향 없음, 대용량 구조체/객체 전달 시 비효율적).
  - `Call by Address`: 포인터 전달 (`NULL` 체크 필요, `>` 연산자 사용).
  - `Call by Reference`: **C++ 권장 방식**. 복사 없이 원본을 직접 조작하며 포인터보다 문법이 간결함.

```cpp
#include <iostream>

// 1. Call by Value (복사본 전달)
void f1(int x){ x = 10; }

// 2. Call by Address (포인터 전달)
void f2(int* p){ *p = 20; }

// 3. Call by Reference (참조자 전달 - C++ 권장)
void f3(int& r){ r = 30; }

int main(){
    int a = 10;
    int& b = a; // b는 a의 별명 (동일한 메모리 주소)

    f1(a); std::cout << a << '\n'; // 10 (변화 없음)
    f2(&a); std::cout << a << '\n'; // 20 (변경됨)
    f3(a); std::cout << a << '\n'; // 30 (변경됨)

    return 0;
}
```

## 12\. `auto` 타입 및 `bool` 타입

- **`auto`** <strong>타입</strong>:

  - **컴파일 타임**에 우변의 초기화 값을 보고 타입을 자동으로 결정함 (동적 타입 언어인 Python/JavaScript와는 다름).
  - **주의사항**: 초기화 값 없이 단순 선언 불가 (`auto x;` ❌). 함수의 매개변수 타입으로 단순 사용 불가 (C++20부터 일부 허용).
- **`bool`** <strong>타입</strong>:

  - `true` (1) 또는 `false` (0) 두 가짓값만 가짐. (크기는 보통 1바이트)

```cpp
#include <iostream>

int main(){
    auto i = 10;          // int로 추론
    auto d = 3.14;        // double로 추론
    bool isReady = true;  // bool 타입

    std::cout << std::boolalpha; // bool 값을 true/false 문자열로 출력
    std::cout << isReady << '\n'; // true
    return 0;
}
```

## 13\. 범위 기반 for 문 (Ranged-based For Loop)

- **개념**: 배열이나 컨테이너(vector 등)의 모든 요소를 순회할 때 사용하는 간결한 반복문 (C++11).
- <strong>성능 최적화 패턴 (</strong><strong>`const auto& x`</strong><strong>)</strong>:

  - `auto x`: 요소를 **복사**해서 가져옴 (대용량 데이터 시 비효율적).
  - `auto& x`: 요소를 **참조**로 가져옴 (원소 수정 가능).
  - `const auto& x`: **복사 비용 없이 읽기 전용**으로 접근 (**가장 많이 쓰이는 베스트 프랙티스**).

```cpp
#include <iostream>

int main(){
    int arr[5] = {10, 20, 30, 40, 50};

    // 1. 값 수정이 필요한 경우 (auto&)
    for (auto& x : arr) {
        x *= 2; // 원본 배열 요소 변경
    }

    // 2. 읽기 전용 순회 (const auto&) -> 성능과 안전성 모두 확보
    for (const auto& x : arr) {
        std::cout << x << ' '; // 20 40 60 80 100
    }
    std::cout << '\n';

    return 0;
}
```
