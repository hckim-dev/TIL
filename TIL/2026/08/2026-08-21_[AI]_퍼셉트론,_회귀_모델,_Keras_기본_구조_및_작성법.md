### 1\. 퍼셉트론 (Perceptron) : AI의 가장 작은 판단 장치

퍼셉트론은 여러 정보를 종합해 **"할까(1)? 말까(0)?"를 판단하는 1개의 의사결정 계산기**입니다.

- <strong>입력값 (</strong><strong>$x$</strong><strong>):</strong> 판단의 재료가 되는 개별 정보 ($x_1$: 스트레스, $x_2$: 배고픔, $x_3$: 잔고)
- <strong>가중치 (</strong><strong>$w$</strong><strong>):</strong> 각 정보에 대해 내가 부여하는 중요도 (예: 다이어트 중이라면 배고픔보다 스트레스에 더 큰 가중치 부여)
- <strong>출력값 (</strong><strong>$y$</strong><strong>):</strong> 중요도를 반영해 모두 합친 점수가 기준선을 넘으면 <strong>실행(1)</strong>, 못 넘으면 **미실행(0)**

> 💡 **한 줄 비유:**
>
> 회의 안건(입력값 3개)을 받아 종합 검토 후 도장을 찍는 **팀장님 1명 = 퍼셉트론 1개**

### 2\. 머신러닝의 3단계 학습 프로세스

머신러닝은 컴퓨터가 "오차를 줄여가며 가장 적합한 규칙(선)을 찾아내는 과정"입니다.

|  |  |  |
| --- | --- | --- |
| **단계** | **명칭** | **설명** |
| **Step 1** | **가설 설정 (Hypothesis)** | 데이터를 가장 잘 설명할 수 있는 모델(수식)을 정의 (예: 데이터 사이를 통과하는 최적의 직선 긋기 $\rightarrow$ 선형 회귀) |
| **Step 2** | **손실 함수 (Cost / Loss)** | 모델의 예측값과 실제 정답 사이의 \*\*오차(틀린 정도)\*\*를 계산하는 채점 기준 |
| **Step 3** | **학습 (Training)** | 오차(Cost)가 최소가 되도록 가중치($w$)를 반복 수정하는 과정 |

<a id="notion-3c21d46c18fc806eb7d7c85896c53be7"></a>

### 3\. 핵심 하이퍼파라미터 : AI를 어떻게 가르칠 것인가?

**1\) 에폭 (Epoch) : "문제집 완독 횟수"**

전체 학습 데이터를 처음부터 끝까지 빠짐없이 1번 공부한 단위입니다.

- **10 Epoch:** 문제집 1권을 오답 체크해가며 총 10회독 반복 학습
- **너무 적을 때 (과소적합, Underfitting):** 공부량이 부족해 시험 점수가 안 나옴
- **너무 많을 때 (과적합, Overfitting):** 문제의 원리가 아닌 답 번호 자체를 외워버려 새로운 실전 문제를 못 풂

**2\) 러닝 레이트 (Learning Rate, 학습률) : "정답을 찾아가는 보폭"**

오차를 줄이기 위해 가중치를 한 번에 얼마나 크게 수정할지 결정하는 수치입니다.

- **너무 크면:** 껑충껑충 뛰다가 정답 골짜기를 지나쳐 튕겨 나감 (학습 실패/발산)
- **너무 작으면:** 발걸음이 너무 좁아 학습 완료까지 시간이 지나치게 오래 걸림
- **실전 권장값:** 보통 `0.001`, `0.0001` 같은 작은 소수점으로 세밀하게 조정

### 4\. tf.keras 핵심 흐름 &amp; 주요 함수

Keras는 복잡한 수식을 직접 짜지 않고 레고 블록처럼 층(Layer)을 쌓아 신경망을 만드는 고수준 도구입니다.

- **`tf.keras.Input(shape=(2,))`** <strong>(입구 규격):</strong> 한 번에 들어올 데이터의 특성(Feature) 개수를 정의 (예: 키, 몸무게 등 2개)
- **`tf.keras.layers.Dense(2)`** <strong>(연산 장치):</strong> 데이터를 받아 가중치 연산 후 결과값 2개를 내놓는 **퍼셉트론(뉴런) 2개**
- **`model.compile()`** <strong>(학습 방법 설정):</strong> 오차 측정 공식(Loss)과 가중치 수정 알고리즘(Optimizer) 지정
- **`model.fit()`** <strong>(학습 진행):</strong> 준비된 데이터를 바탕으로 문제집 풀기(가중치 업데이트) 반복
- **`model.evaluate()`** <strong>(성능 평가):</strong> 학습에 쓰이지 않은 시험용(Test) 데이터로 최종 점수(Loss, 정확도) 채점
- **`model.predict()`** <strong>(실전 추론):</strong> 새로운 입력값을 넣고 모델의 최종 예측 결과 확인

<a id="notion-3c21d46c18fc80fc8d8bd9d98e8a99bd"></a>

### 5\. 간단한 실전 코드 예제 (선형 회귀: $y = 2x - 1$)

```python
import numpy as np
import tensorflow as tf

# 1. 데이터 준비
X = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
y = np.array([-3.0, -1.0, 1.0, 3.0, 5.0, 7.0], dtype=float)

# 2. 모델 구조 정의 (Input을 명시적으로 추가)
model = tf.keras.Sequential([
    tf.keras.Input(shape=(1,)),        # 🚪 1. 입구 규격: 데이터 1개씩 들어옴
    tf.keras.layers.Dense(units=1)     # 🧠 2. 퍼셉트론 1개가 계산해서 결과 1개 출력
])

# 3. 모델 컴파일
model.compile(optimizer=tf.keras.optimizers.SGD(learning_rate=0.01), loss='mean_squared_error')

# 4. 모델 학습
model.fit(X, y, epochs=500, verbose=0)

# 5. 예측
print("X가 10일 때 예측값:", model.predict(np.array([[10.0]])))
```

### 6\. Keras 모델 구축 3가지 방식

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **방식** | **난이도** | **특징** | **비유** | **주 사용처** |
| **Sequential** | ★☆☆ | 위에서 아래로 순서대로 쌓기 | 직진하는 기차 칸 | 입문 실습, 단순 선형/회귀 모델 |
| **Functional** | ★★☆ | 입출력을 직접 연결하여 유연하게 설계 | 레고 조립, 입체 교차로 | **실무 표준**, 복잡한 CNN, 잔차 연결(ResNet) |
| **Subclassing** | ★★★ | 클래스(`tf.keras.Model`) 상속 후 직접 구현 | 맞춤 수제작 | 최신 논문 연구, PyTorch 스타일의 동적 제어 |

### 7\. 3가지 방식 코드 비교

```python
import tensorflow as tf

# 1. Sequential 방식 (초급: 직관적인 순차 쌓기)
model_seq = tf.keras.Sequential([
    tf.keras.Input(shape=(1,)),
    tf.keras.layers.Dense(8, activation='relu'),
    tf.keras.layers.Dense(1)
])

# 2. Functional 방식 (중급/실무: 입력과 출력을 명시적으로 연결)
inputs = tf.keras.Input(shape=(1,))
x = tf.keras.layers.Dense(8, activation='relu')(inputs)
outputs = tf.keras.layers.Dense(1)(x)
model_func = tf.keras.Model(inputs=inputs, outputs=outputs)

# 3. Model Subclassing 방식 (고급: 파이썬 클래스로 직접 제작)
class CustomModel(tf.keras.Model):
    def __init__(self):
        super().__init__()
        self.dense1 = tf.keras.layers.Dense(8, activation='relu')
        self.dense2 = tf.keras.layers.Dense(1)

    def call(self, inputs):
        x = self.dense1(inputs)
        return self.dense2(x)

model_sub = CustomModel()
```

### 8\. 선형 회귀 (Linear) vs 로지스틱 회귀 (Logistic)

|  |  |  |
| --- | --- | --- |
| **구분** | **선형 회귀 (Linear Regression)** | **로지스틱 회귀 (Logistic Regression)** |
| **목적** | **연속적인 숫자(값)** 예측 (회귀) | **Yes/No 범주 및 확률** 예측 (분류) |
| **출력 형태** | 실수 전체 ($-\infty \sim +\infty$) | <strong>0과 1 사이의 확률 (</strong><strong>$0 \le P \le 1$</strong><strong>)</strong> |
| **활성화 함수** | 없음 (직선의 방정식: $y = wx + b$) | **시그모이드 (Sigmoid)** |
| **손실 함수 (Loss)** | **MSE (평균 제곱 오차)** | **Binary Cross-Entropy (로그 손실)** |
| **대표 예시** | 공부 시간에 따른 **시험 점수 (0\~100점)** | 공부 시간에 따른 **합격(1) / 불합격(0)** |

- **선형 회귀 (Linear):** 데이터를 관통하는 최적의 **직선**을 그어 이어지는 수치를 예측
- **로지스틱 회귀 (Logistic):** 직선 수식을 시그모이드(S자 곡선)에 통과시켜 0\~1 사이 확률로 압축한 뒤, 기준값(보통 0.5)을 넘으면 1, 못 넘으면 0으로 최종 판단
